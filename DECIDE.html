组件默认适配主题

2026-10-11 · 源码与预置组件已实现，待手动验收

将独立 HTML 组件改为默认适配演示文稿主题。组件负责 HTML 结构、独立布局 CSS 和必要行为；通用视觉属性通过公共样式类或主题变量获取。

  • 颜色、字体等通用视觉属性默认跟随当前主题，切换主题时无需 Agent 为每个组件额外建立映射。
  • 保留有实际用途的组件变量，允许局部覆盖；未覆盖时回退到对应主题变量。
  • 组件内已有可复用的公共样式角色应优先复用，避免维护重复的基础视觉定义。
  • 保留组件的内容结构、布局和必要行为，不修改页面的全局主题变量。
  • 独立预览需要固定备用值时，将其置于主题变量之后，避免遮蔽主题提供的值。

变量关联示例：

color: var(--stat-badge-accent, var(--color-primary, #325fa8));

验收目标：同一份组件 HTML 在不同主题下自动使用相应的通用视觉样式，局部覆盖仍然有效，内容与结构保持一致。

接口与手动验收说明见 主题公共样式与组件适配；已初始化的本机预置资源需通过现有维护入口显式更新。
