Create or fully replace an unapproved plan and submit it for user approval. Submit this call alone. Organize `content` under `## Goal`, `## Approach`, and `## Acceptance Criteria`, translating the headings when needed to match the user’s language. Put the complete ordered execution steps only in `steps`. Approval returns `status=success`. A refusal returns `status=refuse` and may include the user’s reason or revision instructions in `feedback`. The plan and its assigned step IDs are automatically supplied in `<current_plan>` within `<runtime_context>`.
