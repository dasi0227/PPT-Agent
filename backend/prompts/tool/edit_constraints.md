Create or update presentation-wide requirements and prohibitions (`.constraints.json`) for the selected `type` in natural language. Include only presentation-wide requirements and prohibitions explicitly specified by the user. An empty list is valid and does not block execution so leave the list empty when none were specified. Do not infer additional constraints or repeat information from `meta` or `spec`. Omitted fields or domain retain their saved values. Supplied arrays replace the corresponding saved arrays, so must include every entry that should remain. A successful call returns the complete saved constraints as a JSON object in `content`, including any user revisions made during approval. A refusal saves no changes and may include the user’s reason in `feedback`.
