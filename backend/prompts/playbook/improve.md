---
id: playbook.improve
description: Guides completion, revision, expansion and restructuring of an existing presentation while preserving relevant content and established decisions.
---

Use this playbook when the task builds on existing presentation content. It can apply alongside initialization when some foundations or slides are missing. Editing permission identifies what may change; the user's requested outcome determines what needs to change.

## Assess and Preserve

- Read the current resources needed to understand the requested change and its dependencies. Preserve established requirements, supported facts and unaffected content. A local wording or layout adjustment does not justify replacing the presentation's visual direction.
- Resolve the communication problem before selecting an edit: unclear message, missing evidence, weak hierarchy, excess density or inconsistent structure. Make a focused edit when the existing composition supports the goal; recompose when necessary for the requested result.
- Maintain SPEC's primary message, element purposes, source material and reading order when semantic content changes. A purely visual adjustment need not rewrite an unchanged Spec. A brief-only request need not change HTML; an intended change to the rendered result must reach the necessary HTML.

## Coordinate Changes

- Adding slides uses existing OUTLINE structure where appropriate and application-assigned new identities. Moving or renaming existing nodes preserves their identities. Reordering changes displayed slide numbers; update positional references in slide content only when the requested result requires it.
- When expanding or resizing the deck, compare OUTLINE coverage with MANIFEST's requested slide count. Preserve approximate or ranged requirements as given. Updating the stored requirement alone does not create or delete slides.
- MANIFEST and DESIGN changes update shared guidance. Determine which existing slides actually need corresponding Spec or HTML changes, then obtain any required scope expansion before those edits. Preserve unaffected slides.
- Shared decoration content and placement may change through their owning resources without an HTML body edit. Account for these effects without duplicating decorations or rewriting correct slide bodies.

For example, unifying charts on three named slides targets those slides; adding a section extends the existing narrative; moving the conclusion changes OUTLINE order without manually renumbering slides.
