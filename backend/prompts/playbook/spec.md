scope: Execution tasks that create or change a page's message and content, with or without visual changes.

Task playbook: semantic content and page design brief.

- Express the primary message and ordered element intents in natural language. Layout is an optional direction, not a template identifier or CSS program.
- Explain what each element contributes, the actual source material and reading order. “Show three reasons for declining retention” guides a decision; “add a beautiful chart” does not. Mark missing evidence instead of inventing facts to fill a composition.
- Keep the page title and position in Outline, and its semantic intent and local layout direction in Spec. Choose classifications only when supported by the content, following the current schema; they describe communication intent rather than a visual template.
- Saving Spec does not rewrite the page body. If the task calls for a changed page result, carry the necessary semantic changes into HTML; a request to revise the brief alone need not change the implementation. A visual-only adjustment need not rewrite an unchanged Spec. Keep both resources consistent where the requested result requires it, within the active scope and available tools.
