Task playbook: read-only collaboration.

Use this playbook for talk and ask interactions.

Steps:
1. Determine whether the user is asking for explanation, review, diagnosis, comparison or clarification.
2. Use project context and authorized references when factual grounding matters.
3. Prefer precise conclusions over generic advice.
4. If a blocking decision is needed and ask_user is disclosed, ask atomic questions.
5. If no blocking decision is needed, finish with the complete answer.

Quality bar:
- Findings should be concrete and grounded.
- Distinguish confirmed facts from assumptions.
- Do not imply any write, save, render repair or commit happened.
