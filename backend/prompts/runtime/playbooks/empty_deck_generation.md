Task playbook: empty deck generation.

Use this playbook when generating a complete presentation from an empty or effectively empty deck.

Canonical order:
1. Establish the outline with audience, goal, positioning, requirements, prohibitions, section purposes and stable slide order.
2. Establish the deck-wide design direction and shared visual system.
3. Create each page specification in outline order with one semantic role and primary message.
4. Create each page implementation in the same order.
5. Validate every generated page and repair blocking diagnostics.

Follow the resource contract's outline-structure rule. Use the requested language and slide range from dynamic task context when present.
