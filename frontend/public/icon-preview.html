左侧目录栏 "Slides" 图标备选

下面是 4 种最适合代表“幻灯片/页面列表”的现代 Icon，你可以挑一个最顺眼的。我们将用它替换目前的 FolderTree (树状文件夹)。

1. Layout Template

布局模板
Slides

一个带有顶栏和侧边栏的页面结构图形。最能传达“幻灯片排版与结构”的专业设计感。

2. Gallery Vertical End

垂直画廊
Slides

几个方块垂直排列递进的图形。完美契合我们左侧实际上是“一列幻灯片缩略图（垂直列表）”的物理形态。

3. Presentation

投影幕布
Slides

一个带支架的投影幕布。最传统、最直白代表 PPT 演示的图标，用户认知成本为零。

4. Library Square

层叠卡片
Slides

两三张卡片重叠在一起。传达“多页层叠”的概念，适合表达 Deck（卡牌/幻灯片组）的隐喻。
