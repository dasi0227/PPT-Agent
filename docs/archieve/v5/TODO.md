## 一、将启动简报与交接简报直接用于新会话

需求：让已有的启动简报、交接简报直接接续创作，省去手工新建会话和粘贴，降低接续任务的操作成本。

功能：

- [x] 在简报卡片中按当前选中版本新建同项目会话，并将该版本正文放入独立输入草稿。
- [x] 用户可编辑草稿、选择模型和交互模式，再按普通消息启动任务。
- [x] 新任务加载当前项目上下文，提示词明确当前项目事实优先于历史简报。

## 二、统一 HTML 画布与预览、渲染行为

需求：消除提示词、主题与渲染环境的尺寸差异，以固定设计画布和统一 Runtime 信息支撑编辑、预览与交付，避免同一页面在不同场景中布局错位。

功能：

- [x] 统一使用 1920×1080 CSS px、16:9 画布，贯通 Schema、主题、提示词、预览、截图及导出。
- [x] Runtime 负责设计画布的等比缩放与居中，适配主编辑区、缩略图和全屏；页面 HTML 使用固定画布坐标。
- [x] Runtime Frame 统一传递页序、页码可见性、章节和演示标题，预览、截图与导出据此生成公共装饰。
- [x] 渲染器拒绝不符合 Runtime 画布的尺寸，真实 Chromium 测试覆盖画布大小、溢出与公共装饰注入。

## 三、支持选定多页的批量修改，重构范围选择

需求：让用户一次指定当前页、多页、章节或整套的修改范围，并将写权限与实际任务进度分开管理，支持安全批量修改和部分完成后的接续。

功能：

- [x] 支持当前页、自选多页、自选章节和全部页面，并独立选择设计稿、HTML、演示文稿或全局对象权限。
- [x] 后端将范围解析为稳定页面 ID，允许读取其他页面作为参考，按对象能力与目标集合限制写入；全局对象联动全部页面。
- [x] 支持原 Run 内请求扩权，用户批准、拒绝或调整后继续，活动范围通过响应与事件更新。
- [x] 后端使用独立 WorkLedger 记录实际工作页的待处理、处理中、完成和失败状态，并纳入完成检查与运行检查点恢复；仅获授权但没有任务的页面不会阻塞完成。

## 四、上传图片与参考图，让 Agent 基于视觉素材创作

需求：直接接收截图、品牌图和视觉参考，保留文字描述难以表达的布局与风格细节，并让图片在后续修改、上下文压缩和交付中持续可用。

功能：

- [x] 支持文件选择和剪贴板粘贴 PNG、JPG/JPEG、WebP，可一次添加多张；单图最大 10 MiB、40 MP，每条消息最多 8 张。
- [x] 图片选中后立即上传，服务端校验实际格式和像素数，保留原图并生成 WebP 缩略图；成功后显示附件卡，失败通过输入框错误提示反馈。
- [x] 图片作为项目资产保存，移除消息引用不删除原图；新任务和运行中追加指令均可携带图片。
- [x] 附件发送受模型视觉能力约束，图片进入模型上下文；Agent 可通过 `read_image` 按需读取缩略图或原图，并取得可嵌入 HTML 的原图路径。
- [x] 保留附件 ID、文件名、尺寸、格式、哈希与消息引用顺序，压缩后仍可重新读取项目原图。

需求：把用户看到的页面对象转成可定位的结构化修改意图，减少反复描述位置，使 Agent 能结合当前 HTML 执行局部修改。

功能：

- [x] 引用携带页面 ID、HTML revision/hash、1920×1080 坐标、定位指纹、受限 HTML、盒模型与布局样式；服务端校验数据和体积限制。
- [x] 后端静默合并选择所需的页面与对象 Scope；选区作为软约束，模式与工具写权限继续生效，公共装饰按全局设计处理。
- [x] 按会话隔离草稿快照、编号与注释，支持草稿标记跳页、去重和删除状态反馈；页面更新后不自动重定位旧选区。
- [x] 消息发送成功后清除草稿标记，历史保留编号和注释查看；上下文压缩保留来源摘要，提示 Agent 修改前读取当前内容。

- [x] 按模式、对象权限和单页/多页组装提示词与真实 Schema，隔离静态政策和用户、项目、引用等动态材料；扩权后重新组装契约。
- [x] 允许逐页、分批、局部 patch 或重写，不强制先完成所有设计稿，不要求简单修改固定调用计划或 Reviewer。

## 七、导出可独立使用的 HTML、图片和 PDF

需求：提供离开编辑器仍可使用的整套交付物，冻结导出时的页面与资源，避免内容混版，并让用户看到生成进度、失败原因和下载入口。

功能：

- [x] 按冻结页面顺序导出 HTML ZIP，包含基础样式、主题、项目图片原图和播放器，解压后可通过 `file://` 打开，支持按钮翻页、页数和全屏。
- [x] 导出整套 1920×1080 PNG ZIP 和由同一栅格页面组成的宽屏 PDF，复用渲染器与 Runtime Frame。
- [x] 创建导出时检查运行冲突、取得项目锁并冻结内容快照与摘要，后续修改不会混入本次产物。

- [x] 列出全部缺少 HTML 的页面并阻止整单导出；按最新设计允许导出已有但过期的 HTML，不跳过缺失页、不输出残缺成品。

实现依据：[项目 Checkpoint 回退与恢复设计](docs/spec/2026-09-12-project-checkpoint-rollback-design.md)。

- [x] 起始用户消息复制按钮右侧提供回退，弹窗展示权威时间、影响数量、文件概览与草稿替换提示。

- [x] 连续回退只保留一个恢复到最新入口，恢复原草稿及最后任务之后的手动修改，刷新和重启后仍可恢复。

## 十、预测并快捷填入下一步需求

需求：Agent 完成一次任务后，根据当前项目状态、会话上下文、用户刚完成的目标和仍可继续推进的工作，预测最多三个具体、可执行的下一步输入。输入框为空且当前可编辑时，在输入框内部以可交互的 placeholder 风格建议层展示候选项；用户可按 `Option + 1/2/3` 将对应候选填入原输入框，也可忽略候选直接输入，降低连续创作时组织下一条指令的成本。

实现依据：[下一步输入预测与快捷填入设计](docs/spec/2026-09-14-next-input-suggestions-design.md)。

建议展示：

```text
按「Option + 序号」选择或直接输入下一步需求
1. xxx
2. xxx
3. xxx
```

功能：

- [x] 每次任务成功完成时生成零至三个与当前结果紧密相关、彼此不重复、可直接作为用户指令发送的下一步输入；候选与最终回复分字段传递，不混入回复正文和模型历史。
- [x] 候选作为最终消息的附属数据持久化并随会话历史恢复；项目或会话切换后只展示当前会话最近一次有效候选，避免跨上下文串用。
- [x] 仅在任务空闲、输入框可编辑且整个消息草稿为空时，在输入框内完整展示提示与现有候选；输入或添加引用后隐藏，内容再次清空时重新展示同一组候选。
- [x] macOS 下监听 `Option + 1/2/3`，其他平台使用对应的 `Alt + 1/2/3`；命中后只把候选纯文本填入原输入框并聚焦到文本末尾，不自动发送，不自动改变模式、模型、技能、附件或修改范围。
- [x] 快捷键处理避开中文输入法组合态、斜杠菜单、候选菜单、弹窗及其他可编辑控件，不覆盖系统或浏览器已有交互；同时提供可被辅助技术读出的操作说明。
- [x] 新任务开始、项目状态使候选失效或当前任务失败/取消时不展示过期候选；候选生成或解析失败不得阻断任务完成，输入框回退为普通 placeholder。
- [x] 后端限制候选数量、单项长度和总大小，并执行去空、去重与纯文本规范化；前端不得把候选作为 HTML 注入。
- [x] 覆盖候选生成与协议校验、SSE 和历史恢复、项目/会话隔离、空值回显、快捷键填入、IME 与菜单冲突、失败降级及窄宽度换行的测试。
