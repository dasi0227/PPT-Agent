# 目录结构树形差异

日期：2026-10-01。状态：已实施，待手动验收。

## 展示

沿用已确认的 [目录原型](../demo/2026-09-30-final-change-summary-demo.html)，最终总结和单次工具编辑共用差异卡片。目录不再按普通 JSON 字段排列；按受影响章节分组，保留章节、子章节、页面的层级和顺序。章节显示 `01`，子章节显示 `01.1`；子章节缩进一级，其页面再缩进一级。

旧值为红色 `−`，新值为绿色 `+`；未修改节点直接以淡色展示，不提供目录内部的省略折叠按钮。节点移动只在旧位置与新位置显示红绿行，不展示「移至／来自」。章节或子章节的标题修改显示旧、新标题，子节点仅展示一次；目的修改在该节点下单独显示旧、新目的。

新增、删除整棵子树时，其节点和后代都使用相应颜色。移动已有章节或子章节时，没有独立变化的后代作为淡色上下文展示，不重复计数。只保留含实际变更的章节分组；受影响章节内未修改的节点保留，用于理解层级。

文件名旁边显示绿色、红色计数，每个可见变更行计为一项，上下文不计数。一个节点同时改名和移动时，旧位置、新位置各计一次；目的仍独立计数。目录沿用差异卡片的长内容展开、内部水平滚动、预览按钮和全局颜色。

## 前后端结构

`ArtifactDiff.kind` 增加 `outline`，使用 `groups: OutlineDiffGroup[]`；每个分组包含 `rows[]`，行具有：

- `kind`：`context`、`removed`、`added`。
- `node`：`chapter`、`subchapter`、`page`、`purpose`。
- `depth`：章节为 0，子章节为 1；直属页面和章节目的为 1，子章节页面和目的为 2。
- `title`：冻结的标题或目的文本。
- `order`：可选的章节或子章节编号。

前后端直接使用新投影，不重新读取当前目录，也不从旧字段差异重建目录。节点 ID 只用于后端匹配，不暴露在展示中。新旧快照以稳定 ID 匹配兄弟序列；单纯插入、删除导致的编号顺延不产生虚假移动，父节点改名不产生后代变更。

## 手动验收

遵循项目约定，未运行测试、构建或浏览器自动验证；已在现有差异回归文件补充子树和移动的复杂逻辑用例。

- 修改章节标题或目的：旧、新值成对显示，未变化页面保留为淡色上下文。
- 在已有子章节修改页面标题：页面缩进两级，只显示该页面的旧、新标题。
- 新增、删除整棵子章节：子章节及各页面分别计数并显示相应颜色。
- 移动页面、子章节或章节：旧、新位置显示红绿行；移动祖先不使未变化页面重复计数。
- 插入页面或子章节：原有兄弟的编号自然顺延，不产生额外红绿行。
- 完成后继续编辑、重载历史：先前差异的内容、层级和计数保持冻结。
