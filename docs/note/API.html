项目

已确认
操作 方法 请求字段 响应字段
读取项目列表 GET /api/projects 无
  • items：项目列表，无项目时为 []
  • items[].id：项目 ID
  • items[].title：项目名称
  • items[].updated_at：更新时间，毫秒时间戳
读取项目文件 GET /api/projects/{project_id}
  • project_id：项目 ID
  • meta：基本信息对象，含 title、language、count、audience、goal 五个字符串；未建立为 null
  • constraint：约束对象，content 与 visual 各含 requirements、prohibitions 字符串数组；未建立为 null
  • outline：大纲对象，未建立为 null。sections 为有序章数组，章含 id、title、slides、subsections，节含 id、title、slides，幻灯片含 id、title。空列表为 []
  • slides：按 slide_id 索引，每项包含 spec 与 html。spec 沿用 {slide_id}.json，含 purpose、core、elements、layout；格式错误时返回 null。html 为源码字符串，已存在的空 HTML 返回空串。文件缺失时对应值为 null，没有幻灯片时为 {}
  • hashes：含 meta、constraint、outline 的哈希及 hashes.slides，其中页键与 slides 相同。缺失文件的哈希为 null；损坏的规格保留原始文件哈希
读取项目外观 GET /api/projects/{project_id}/appearance
  • project_id：项目 ID
  • theme_id：当前主题资产 ID，未选择主题时为 null
  • positions：四个位置字段 slide_pagination、deck_title、section_title、logo，取值为 none / top-left / top-center / top-right / bottom-left / bottom-center / bottom-right，none 表示隐藏
  • logo：布尔值，已上传为 true，未上传为 false
读取缩略图 GET /api/projects/{project_id}/slides/{slide_id}/thumbnail
  • project_id：项目 ID
  • slide_id：项目内的幻灯片 ID
  • 响应体：image/webp
读取标志图 GET /api/projects/{project_id}/logo
  • project_id：项目 ID
  • 响应体：image/png
创建项目 POST /api/projects/create
  • title：非空白项目名称，提交值最多 60 个 UTF-16 代码单元，按原样保存

新项目默认无主题。

 id：新项目 ID
更新项目 POST /api/projects/update
  • project_id：需修改的项目 ID
  • title：非空白项目名称，提交值最多 60 个 UTF-16 代码单元，按原样保存
 无
保存标志图 POST /api/projects/logo/save
  • project_id：项目 ID
  • file：用于上传或替换 Logo 的 multipart PNG 文件，最多 2 MB（2,000,000 字节）
 无
保存项目主题 POST /api/projects/theme/save
  • project_id：必填，项目 ID
  • theme_id：必填，主题资产 ID

每次保存都需选择存在、已启用且正文非空白的主题。同值保存也执行校验。

 无
保存装饰位置 POST /api/projects/positions/save
  • project_id：必填，项目 ID
  • slide_pagination：必填，页码位置
  • deck_title：必填，文稿标题位置
  • section_title：必填，章节标题位置
  • logo：必填，标志图位置

位置取值与读取项目外观一致。

 无
保存基本信息 POST /api/projects/meta/save
  • project_id：项目 ID
  • base_hash：打开编辑器时的内容哈希，可为 null，仅在预期文件尚不存在时创建
  • meta：基本信息对象，含 title、language、count、audience、goal 五个字符串；首次建立可传空串
  • hash：已保存正文的内容哈希，字符串
保存全局约束 POST /api/projects/constraint/save
  • project_id：项目 ID
  • base_hash：打开编辑器时的内容哈希，可为 null，仅在预期文件尚不存在时创建
  • constraint：约束对象，content 与 visual 各含 requirements、prohibitions 两个有序字符串数组；空清单传 []
  • hash：已保存正文的内容哈希，字符串
保存目录大纲 POST /api/projects/outline/save
  • project_id：项目 ID
  • base_hash：打开编辑器时的内容哈希，可为 null，仅在预期文件尚不存在时创建
  • outline：大纲对象，含 sections 有序章数组；空大纲为 {"sections":[]}
  • hash：已保存正文的内容哈希，字符串
保存设计稿 POST /api/slides/spec/save
  • project_id：项目 ID
  • slide_id：项目内的幻灯片 ID
  • base_hash：打开编辑器时的内容哈希，可为 null，仅在预期文件尚不存在时创建
  • spec：完整规格对象，沿用现有 {slide_id}.json 文件格式
  • hash：已保存正文的内容哈希，字符串
保存幻灯片 POST /api/slides/html/save
  • project_id：项目 ID
  • slide_id：项目内的幻灯片 ID
  • base_hash：打开编辑器时的内容哈希，可为 null，仅在预期文件尚不存在时创建
  • html：完整 UTF-8 HTML 源码，字符串
  • hash：已保存正文的内容哈希，字符串
删除项目 POST /api/projects/delete
  • project_id：项目 ID
 无

  • project_id：项目 ID

资产

已确认
操作方法 请求字段响应字段
读取资产列表 GET /api/assets?type={type}&query={query}
  • type：theme / component / skill / snippet
  • query：可选，按名称、描述或标签名搜索；短语同时匹配正文
  • items：资产摘要数组，包含启用和停用资产，统一按 updated_at 降序、name 升序、id 升序排列；无结果为 []
  • items[].id：稳定资产 ID
  • items[].type：theme / component / skill / snippet
  • items[].name：显示名
  • items[].description：描述
  • items[].content：null，正文从资产详情读取
  • items[].enabled：布尔值，是否启用
  • items[].tag_ids：同类标签 ID 数组
  • items[].updated_at：最后修改时间，毫秒时间戳
读取标签字典 GET /api/assets/tags?type={type}
  • type：theme / component / skill / snippet
  • items：同类标签数组，按名称、ID 排序
  • items[].id：标签 ID
  • items[].name：显示名称
创建标签 POST /api/assets/tags/create
  • type：必填，theme / component / skill / snippet
  • name：必填，不能为空白，同一类型内按原名称保持唯一
 id：新标签 ID
更新标签名称 POST /api/assets/tags/update
  • tag_id：必填，已有标签 ID
  • name：必填，不能为空白，同一类型内按原名称保持唯一
 无
删除标签 POST /api/assets/tags/delete
  • tag_id：必填，要从标签字典删除的标签 ID
 无
读取资产详情 GET /api/assets/{asset_id}
  • asset_id：资产 ID
  • id：稳定资产 ID
  • type：资产类型
  • name：保存后的显示名
  • description：保存后的描述
  • enabled：布尔值，是否启用
  • tag_ids：保存后的同类标签 ID 数组
  • updated_at：最后修改时间，毫秒时间戳
  • content：主题 CSS、组件 HTML、技能 Markdown 或短语纯文本
创建资产 POST /api/assets/create
  • type：theme / component / skill / snippet
  • name：提交值不能为空白，最长 80，按原样保存，同一类型内按原名称保持唯一
  • description：提交值不能为空白，最长 500，按原样保存
  • content：该类型的完整正文
  • tag_ids：可选，同类标签 ID 数组，默认空数组

新资产默认启用。type、name、description 和 content 均需提供。

 id：新资产 ID
更新资产 POST /api/assets/update
  • asset_id：已有资产的 ID
  • name：提交值不能为空白，最长 80，按原样保存，同一类型内按原名称保持唯一
  • description：提交值不能为空白，最长 500，按原样保存
  • content：替换后的完整正文
  • tag_ids：同类标签 ID 数组，传 [] 清空
  • enabled：布尔值，true 启用，false 停用

仅 asset_id 必填。可修改字段省略或为 null 时保留原值。每次成功更新均刷新 updated_at，包括仅提交 ID、可修改字段均为 null 或重复提交相同值。

停用项目正在使用的主题时返回 ASSET_IN_USE，提示“项目正在使用该主题，无法停用”。

 无
删除资产 POST /api/assets/delete
  • asset_id：资产 ID

删除项目正在使用的主题时返回 ASSET_IN_USE，提示“项目正在使用该主题，无法删除”。

 无

已确认
操作方法 请求字段响应字段
读取文件打开设置 GET /api/settings/fileopen 无
  • default_open：system 或应用绝对路径（Windows 为 .exe，其他平台为 .app）
  • json_open：JSON 打开方式，同默认方式，另可为 inherit
  • html_open：HTML / HTM 打开方式，同 json_open
  • custom_apps：自定义应用绝对路径的有序字符串数组，无自定义应用时为 []
保存文件打开设置 POST /api/settings/fileopen/save
  • default_open：system 或应用绝对路径（Windows 为 .exe，其他平台为 .app）
  • json_open：JSON 打开方式，同默认方式，另可为 inherit
  • html_open：HTML / HTM 打开方式，同 json_open
  • custom_apps：自定义应用绝对路径的有序字符串数组，[] 清空
  • default_open、json_open、html_open：实际生效的打开方式，含未登记应用的回退结果
  • custom_apps：路径规范化后按首次出现顺序去重的应用列表
选择本地应用 POST /api/settings/fileopen/pick 无
  • path：字符串或 null；选中应用的规范化绝对路径，用户取消时为 null
读取快捷键 GET /api/settings/shortcuts 无
  • command_trigger：命令，默认 /
  • reference_trigger：综合引用菜单，默认 @
  • component_trigger：组件，默认 $
  • slide_trigger：幻灯片，默认 #
  • snippet_trigger：短语，默认 %
  • previous_slide：上一张，默认 Primary+ArrowLeft
  • next_slide：下一张，默认 Primary+ArrowRight
  • zoom_in：放大，默认 Primary+Equal
  • zoom_out：缩小，默认 Primary+Minus
  • toggle_overview：总览，默认 Primary+KeyO
  • export_deck：导出，默认 Primary+KeyP
  • toggle_view：切换视图，默认 Primary+KeyU
  • toggle_source：切换源码，默认 Primary+KeyI
  • switch_theme：切换主题，默认 Primary+KeyT
  • submit_request：发送指令，默认 Primary+Enter
  • select_suggestion：选择建议共用的单个修饰键，默认 Option，对应数字 1、2、3
保存快捷键 POST /api/settings/shortcuts/save

五个触发符各取 /~!@#$%^&*>\+ 中的一个字符，且互不重复。操作快捷键使用 Primary、Option 或 Alt 中的一个修饰键加一个普通键。组合需避开保留键且互不重复，检查冲突时 Option 与 Alt 等价。

  • command_trigger：命令，默认 /
  • reference_trigger：综合引用菜单，默认 @
  • component_trigger：组件，默认 $
  • slide_trigger：幻灯片，默认 #
  • snippet_trigger：短语，默认 %
  • previous_slide：上一张，默认 Primary+ArrowLeft
  • next_slide：下一张，默认 Primary+ArrowRight
  • zoom_in：放大，默认 Primary+Equal
  • zoom_out：缩小，默认 Primary+Minus
  • toggle_overview：总览，默认 Primary+KeyO
  • export_deck：导出，默认 Primary+KeyP
  • toggle_view：切换视图，默认 Primary+KeyU
  • toggle_source：切换源码，默认 Primary+KeyI
  • switch_theme：切换主题，默认 Primary+KeyT
  • submit_request：发送指令，默认 Primary+Enter
  • select_suggestion：只提交单个修饰键，默认 Option，与数字 1、2、3 分别组成快捷键
 无
读取模型与路由 GET /api/settings/models 无
  • models：完整模型对象数组，至少一项
  • models[].id：稳定的模型配置 ID
  • models[].name：唯一配置名，1–80 字符
  • models[].protocol：responses 或 anthropic
  • models[].base_url：模型基础地址
  • models[].model：上游模型名
  • models[].provider：用户选择的模型品牌，用于图标
  • routes.main_default：主路默认模型配置 ID
  • routes.main_fallback：主路备用配置 ID，null 表示关闭
  • routes.side_default：旁路默认配置 ID
  • routes.side_fallback：旁路共用备用配置 ID，null 表示关闭
  • routes.rename：rename 的模型配置 ID，null 沿用 side_default
  • routes.compact：compact 的模型配置 ID，null 沿用 side_default
  • routes.commit：commit 的模型配置 ID，null 沿用 side_default
  • routes.polish：polish 的模型配置 ID，null 沿用 side_default
  • routes.handoff：handoff 的模型配置 ID，null 沿用 side_default
  • routes.suggest：suggest 的模型配置 ID，null 沿用 side_default
读取单个模型配置 GET /api/settings/models/{id} id：模型配置 ID
  • id：稳定的模型配置 ID
  • name：生效的配置名
  • protocol：生效的协议
  • base_url：保存后的模型基础地址
  • model：上游模型名
  • provider：保存的模型品牌

  • protocol：responses 或 anthropic
  • base_url：模型基础地址，提供时需为非空白字符串

六个字段均需提供。

 id：新模型配置 ID
更新模型配置 POST /api/settings/models/update
  • id：已有模型配置的 ID
  • name：唯一配置名，提交值不能为空白，最长 80，按原样保存
  • protocol：responses 或 anthropic
  • base_url：模型基础地址，提供时需为非空白字符串
  • provider：模型品牌，可选值为deepseek、kimi、mimo、gpt、claude、gemini、qwen、minimax、glm、grok
  • model：非空白的上游模型名
  • key：只写的非空白密钥

可修改字段省略或为 null 时保留原值，包括密钥。只传 ID 时保留现有配置。

 无

更新单个模型路由 POST /api/settings/routes/save

只接受以下两个字段，未声明的字段返回 INVALID_ARGUMENT。

  • route：main_default、side_default、main_fallback、side_fallback、rename、compact、commit、polish、handoff 或 suggest

开始导出 POST /api/exports/create
  • project_id：字符串，必填，项目 ID
  • format：字符串，必填，png / pdf / html
  • request_id：字符串，必填，前端生成；同一次网络重发复用，主动重新导出使用新值

  • export_id：字符串，必填，导出任务 ID

  • total_slides：正整数，本次导出的幻灯片总数，创建任务时确定
  • filename：字符串或 null；ready 时为导出文件名，其余状态为 null
  • filesize：非负整数或 null；ready 时为导出文件的字节数，其余状态为 null
  • error_message：字符串或 null；failed 时为失败原因，其余状态为 null
取消导出 POST /api/exports/cancel
  • export_id：字符串，必填，停止任务或清理已生成文件
 无

  • export_id：字符串，必填，导出任务 ID
  • 响应体：文件附件；PDF 为 application/pdf，PNG 图片集为 application/zip，单个 HTML 演示文件为 text/html; charset=utf-8，文件名见 Content-Disposition

会话

已确认
操作方法 请求字段响应字段
读取会话列表 GET /api/projects/{project_id}/sessions
  • project_id：项目 ID
  • items：会话数组，最近更新在前，同时间按 ID 升序
  • items[].id：会话 ID
  • items[].title：会话标题
  • items[].updated_at：最近更新时间，毫秒时间戳
  • items[].run_status：字符串或 null；pending / running / waiting / cancelling，没有活动 Run 时为 null
  • items[].has_active_commands：布尔值，必返。是否有非终态旁路命令，用于恢复后台会话的订阅
读取会话状态 GET /api/sessions/{session_id}
  • session_id：会话 ID
  • revision：本次读取的会话版本，十进制字符串
  • plan：生效的计划或 null；含 run_id 和有序 steps，每步有 title、status（pending / processing / completed），最多一步 processing；update_plan 的 steps=null 清空计划
  • context：对象，含 current、total、threshold_min、threshold_max、details，均必返且非 null
  • context.current：非负整数，各明细项 Token 数之和
  • context.total：正整数，总窗口 200000 Token
  • context.threshold_min / threshold_max：正整数，分别为 12000 和 170000 Token
  • context.details：含 system_prompt、runtime、chat_history、read_file、other。各类为有序 {name, tokens} 数组，name 为字符串，tokens 为非负整数，无明细为 []
  • active_run_id：当前会话的非终态 Run ID，无则 null；据此读取状态、进度与待答事项
  • active_command_ids：当前会话非终态旁路命令的 id 数组，无则 []
  • suggestions：当前会话最后一条用户输入之后最近成功的 suggest 结果。无用户输入时取最近成功结果，无匹配则为 []
创建会话 POST /api/sessions/create
  • project_id：所属项目 ID
  • title：可选，会话标题，省略时使用「新会话」
  • id：新建会话的 ID
更新会话 POST /api/sessions/update
  • session_id：已有会话的 ID
  • title：新的会话标题，去除首尾空白后非空
  • expected_revision：十进制字符串。可返回最新且标题实际改变时需提供，取检查点列表的 revision
 无
删除会话 POST /api/sessions/delete
  • session_id：会话 ID
 无
