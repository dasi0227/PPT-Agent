  • hashes：含 meta、constraint、outline 的内容哈希，以及按 slide_id 索引的 spec、html 哈希；文件缺失时对应哈希为 null

资产

已确认
操作方法 请求字段响应字段
读取资产内容 GET /api/assets?kind={kind}&query={query}
  • kind：theme / component / skill / snippet
  • query：可选，按名称、描述或标签名搜索；短语同时匹配正文
  • items：资产摘要数组，包含启用和停用资产，统一按 updated_at 降序、name 升序、id 升序排列；无结果为 []
  • items[].id：稳定资产 ID
  • items[].kind：theme / component / skill / snippet
  • items[].name：显示名
  • items[].description：描述
  • items[].disabled：布尔值，是否停用
  • items[].tag_ids：同类标签 ID 数组
  • items[].updated_at：最后修改时间，毫秒时间戳
读取标签字典 GET /api/tags?kind={kind}
  • kind：theme / component / skill / snippet
  • items：同类标签数组，按名称、ID 排序
  • items[].id：标签 ID
  • items[].name：显示名称
读取资产正文 GET /api/assets/{asset_id}
  • asset_id：资产 ID
  • content：主题 CSS、组件 HTML、技能 Markdown 或短语纯文本，原样返回字符串
  • hash：原文哈希，用于预览缓存和编辑校验
保存资产 POST /api/assets/save
  • asset_id：可选，省略创建资产，传入则更新已有资产
  • kind：创建时必填，theme / component / skill / snippet；更新时省略
  • name：创建时必填，更新时可选；名称去首尾空白后 1–80 字符
  • description：创建时必填，更新时可选；描述去首尾空白后 1–500 字符
  • content：创建时必填，更新时可选；该类型的完整原文字符串，可由前端读取文件获得，更新时省略不修改
  • base_hash：更新且提交 content 时必填，读取正文时的哈希；创建或仅修改摘要时省略
  • tag_ids：可选，标签 ID 数组；创建时默认 []，更新时省略不修改，[] 清空
  • disabled：仅更新时可选，布尔值；true 停用，false 启用；创建默认启用
  • id：稳定资产 ID
  • hash：本次保存后 content 的内容哈希，字符串；摘要字段变化不影响该哈希
  • updated_at：最后修改时间，毫秒时间戳；同值保存时不变
删除资产 POST /api/assets/delete
  • asset_id：资产 ID
 无

消息

已确认
操作方法 请求字段响应字段
读取历史 GET /api/sessions/{session_id}/history?before={before}&limit={limit}
  • session_id：会话 ID
  • before：可选十进制字符串，取上一批响应的 next_before；首次读取省略
  • limit：可选整数，默认 20，范围 1–100
  • revision：本次读取的会话版本，十进制字符串
  • next_before：本批最小分组 seq 的十进制字符串；没有更早记录时为 null
  • items：当前批次的分组，按创建 seq 升序展示，首次取最新一批；无历史为 []
  • items[].seq：分组首条记录的序号，十进制字符串
  • items[].created_at：分组开始时间，毫秒时间戳
  • items[].run：对象，仅 Run 分组返回；含 id、status、scope、instructions、response、active_duration_ms、total_tokens、changes、failure
  • items[].command：对象，仅命令分组返回；含 id、operation_id、kind、status、phase、failure、last_success_id、result
读取变更差异 GET /api/runs/{run_id}/changes
  • run_id：Run ID
  • items：数组或 null，必返；一次返回该 Run 的全部变更差异，无变化为 []，清单尚未生成或不可得为 null
  • items[].target：对象，必返；变更目标，含 part、可选 slide_id、path，与历史 run.changes 的目标一致
  • items[].status：字符串，必返；added / modified / deleted
  • items[].kind：字符串，必返；fields / outline / text / binary / unavailable
  • items[].fields：数组，仅 fields 时必返；每项含 field、可选 label、rows；行含 kind（added / removed）、value
  • items[].groups：数组，仅 outline 时必返；每项含 rows；行含 kind（context / added / removed）、node（section / subsection / slide）、depth、title、可选 order
  • items[].hunks：数组，仅 text 时必返；每项含 old_start、old_count、new_start、new_count、rows；行含 kind、text、可选 old_line、new_line
  • items[].reason：字符串，仅 unavailable 时必返；无法展示的原因；binary 只展示目标和变更类别
读取执行详情 GET /api/runs/{run_id}
  • run_id：Run ID
  • status：pending / running / waiting / cancelling / done / rejected / failed / interrupted / cancelled
  • mode：当前执行模式，chat / ask / plan / create
  • model：启动时选定的模型配置名
  • scope：当前允许的幻灯片 ID 数组或 null；[] 未授权幻灯片
  • revision：本次读取的会话版本，十进制字符串
  • usage：含 input_tokens、output_tokens、total_tokens、call_count 四个非负整数
  • active_duration_ms：已累计的执行毫秒数，扣除等待答复的时间
  • active_since：当前计时段开始的毫秒时间戳，停止计时为 null
  • created_at：受理时间，毫秒时间戳
  • updated_at：最近状态更新时间，毫秒时间戳
  • failure：Run 失败原因 {code, message}，没有为 null
  • activity：字符串或 null，当前活动标识；无活动或 Run 结束为 null
  • commentary：字符串或 null，当前进度说明；无说明或 Run 结束为 null
  • pending：待答项数组，每项含 tool_call_id、kind（question / plan / permission / scope / resource）、version；按 ID 读取表单，无待答项或 Run 结束为 []
  • messages：完整过程消息数组，按 seq 升序；无记录为 []，不分页
  • messages[].id：消息 ID
  • messages[].seq：会话内创建顺序，十进制字符串

  • status：pending / running / cancelling / done / failed / interrupted / cancelled

  • result.status：字符串，result 非 null 时必返；completed / blocked / failed
  • result.text：字符串，可选；工具输出、检查结论或失败原因

  • result.resources：数组，可选；已加载资产的 {kind, id, name} 数组
  • result.command：对象，可选；含 text；已知时含 exit_code、duration_ms、stdout_preview、stderr_preview
  • result.interaction：对象，可选；含 kind、request、answer。kind 与人工模块一致，request 为当时展示的表单内容

接收实时输出 GET /api/sessions/{session_id}/events
  • session_id：会话 ID
  • changed：SSE 事件，data 含 revision、areas。areas 为 history / run / commands / plan / suggestions / context / checkpoints / content / sessions 数组，重读对应数据
