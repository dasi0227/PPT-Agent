接口包

  • controller/<接口包>/按 API 功能分组
  • ├── XxxController.java请求适配与响应组装
  • ├── dto/前端请求对象
  • └── vo/前端响应对象

领域包

  • <领域包>/project／agent／asset／setting
  • ├── model/Entity、值对象、枚举及业务输入与结果
  • │ ├── entity/业务实体
  • │ └── enumeration/业务状态与类型枚举
  • ├── service/业务规则与用例编排
  • ├── repository/业务数据存取接口
  • └── gateway/外部能力接口，按需创建

项目目录

  • {project_id}/
  • ├── .meta.json项目基本信息
  • ├── .constraints.json项目约束
  • ├── .outline.json大纲
  • ├── {slide_id}.json幻灯片规格
  • ├── {slide_id}.html幻灯片源码
  • ├── .git/Git 仓库
  • └── .runtime/
  • ├── render-slides.json按 slide_id 记录最新 screenshot_id 和 hash
  • ├── mutations/
  • │ └── {operation_hash}.json文件修改临时事务记录
  • ├── attachments/
  • │ ├── {attachment_id}.png附件原图
  • │ └── {attachment_id}.webp附件缩略图
  • ├── screenshots/
  • │ └── {screenshot_id}.png截图，ID 全局唯一，内容不覆盖
  • ├── thumbnails/
  • │ └── {slide_id}.webp当前幻灯片缩略图
  • └── exports/导出临时文件
  • └── {export_id}/
  • ├── work/
  • │ └── {序号}-{标题}.png每张 slide 的渲染图片
  • └── {filename}.pdf / .zip / .html本次导出的唯一成品
