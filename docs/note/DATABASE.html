数据库设计

projects

项目

一行对应一个创作项目，保存项目身份、管理名称和项目级设置。

已确定
字段 类型 可空 默认值 业务含义 约束
id TEXT 否 无 项目的稳定标识，不随项目重命名变化。 唯一。
title TEXT 否 无 项目管理名称；与演示文稿内容标题独立。 允许同名。
theme TEXT 是 NULL 当前选中的主题 ID，NULL 表示未选择主题。 非空值引用 assets.id，目标 type 为 theme。
logo BLOB 是 NULL 当前 Logo 的 PNG 图片二进制内容。 —
slide_pagination_position TEXT 否 'bottom-right' 页码的显示位置；none 表示关闭。 none / top-left / top-center / top-right / bottom-left / bottom-center / bottom-right；四项非 none 值互不重复。
deck_title_position TEXT 否 'none' 演示文稿标题的显示位置；不保存标题文字。 取值及互斥规则同页码。
section_title_position TEXT 否 'top-left' 章节标题的显示位置；不保存章节名称。 取值及互斥规则同页码。
project_logo_position TEXT 否 'none' Logo 的显示位置；与图片是否已上传分别保存。 取值及互斥规则同页码；none 不清除 logo。
updated_at INTEGER 否 无 项目最后修改时间，毫秒时间戳；供列表排序及显示。 实际变化时更新，同值保存不更新。

sessions

会话

一行对应项目中的一个会话，保存会话身份、名称、所属项目和当前计划。

已确定
字段 类型 可空 默认值 业务含义 约束
id TEXT 否 无 会话的唯一标识。 唯一。
project_id TEXT 否 无 会话所属的项目。 外键 projects.id，级联删除；索引 project_id。
revision INTEGER 否 0 当前会话的统一提交版本。 与业务变更同事务递增；历史回退不重置。
title TEXT 否 '新会话' 会话名称。 允许同名。
plan TEXT 是 NULL 会话当前生效的执行计划。 {run_id, steps}，每步为 pending / processing / completed，最多一步 processing。update_plan(steps=null) 清空整项。
updated_at INTEGER 否 无 会话的更新时间，毫秒时间戳；供列表排序。 —

runs

执行任务

一行对应一次 Agent 任务；等待回答或审批沿用当前 Run，任务结束后重新发起新 Run。

已确定
字段 类型 可空 默认值 业务含义 约束
id TEXT 否 无 任务的唯一标识。 唯一。
session_id TEXT 否 无 任务所属的会话。 外键 sessions.id，级联删除；同会话最多一条非终态记录。
mode TEXT 否 无 当前执行模式。 chat / ask / plan / create。
model TEXT 否 无 任务选择的模型配置名。 不设外键；配置改名不改写历史值。
scope TEXT 是 NULL 当前允许操作的页面 ID 列表。 JSON 幻灯片 ID 数组；NULL 表示不限本项目幻灯片，[] 表示未授权。
status TEXT 否 'pending' 任务的执行状态与结束结果。 pending / running / waiting / cancelling / done / rejected / failed / interrupted / cancelled。
changes TEXT 是 NULL 任务结束时冻结的自身已提交净修改差异。 JSON 数组，保存目标、变更类别与差异；[] 表示无净变化，NULL 表示尚未生成或不可用。
error TEXT 是 NULL 导致整个任务失败的具体错误。 JSON 对象 {code, message}；无对应错误时为空。
input_tokens INTEGER 否 0 累计主循环对话已报告的输入 Token 数。 非负整数；同一次调用的用量不重复累计。
output_tokens INTEGER 否 0 累计主循环对话已报告的输出 Token 数。 非负整数；同一次调用的用量不重复累计。
total_tokens INTEGER 否 0 累计主循环对话已报告的总 Token 数。 使用供应商报告的总量。
call_count INTEGER 否 0 累计主循环对话的实际模型请求次数，含重试。 非负整数；包含未报告 Token 用量的调用。
active_duration INTEGER 否 0 已累计的有效执行时长。 不计等待回答和审批的时间。
active_since INTEGER 是 NULL 当前有效计时段的起点。 非计时状态为 NULL。
created_at INTEGER 否 无 任务的创建时间。 —
updated_at INTEGER 否 无 任务的更新时间。 —

messages

消息

一行对应一条消息，统一保存正文、引用和用户输入处理状态。

已确定
字段 类型 可空 默认值 业务含义 约束
id TEXT 否 无 消息的全局唯一标识。 唯一；重复提交复用原 ID。
session_id TEXT 否 无 消息所属的会话。 外键 sessions.id，级联删除。
run_id TEXT 是 NULL 消息所属的执行任务。 外键 runs.id，会话须一致；会话级手动压缩摘要可为空。
seq INTEGER 否 无 消息在会话中的固定顺序。 与 commands.seq 在会话内共同唯一，创建后不变。
type TEXT 否 无 消息的业务用途。 instruction / response / thinking / commentary / tool_call / tool_result / summary；每个 Run 最多一条 response。
content TEXT 否 无 正文、引用及工具内容。 合法 JSON。instruction 保存 text、有序 references 及可选 scope。DOM 引用保存 type=dom、slide_id、html、comment 和必要定位信息；图片引用保存 type=image、attachment_id；其他引用保留稳定 ID 及必要信息。引用的正文和附件字节由各自存储管理。response / thinking / commentary / summary 保存 JSON 字符串，tool_call 保存 {name, arguments}，tool_result 保存实际结果，保持图文顺序。
raw TEXT 是 NULL 后续模型调用要求携带的原生协议数据。 合法 JSON，含必要的原生协议数据和来源信息。
tool_call_id TEXT 是 NULL 关联工具调用与结果的调用 ID。 tool_call / tool_result 必填，其他类型为 NULL；同一 Run 的同一调用，两种记录各最多一条。
instruction_decision TEXT 是 NULL JEV 对用户输入的分类结果。 仅 instruction 使用：task / gossip / disclosure / bypass / irrelevant；task 使用 Run 模式，gossip 切换当轮提示词、工具为空，其余三类拒绝。未判定或检测失败时为空。
instruction_status TEXT 是 NULL 用户输入的信箱处理状态。 仅 instruction 使用：queued / sent，初始为 queued（尚待处理，包含等待判定）。sent 表示信箱处理完成。其他消息为 NULL。
context_position INTEGER 是 NULL 消息在当前模型上下文中的位置。 非空时同会话唯一；NULL 表示不参与当前上下文。
created_at INTEGER 否 无 消息创建时间。 —

commands

旁路命令

一行对应一次辅助命令执行，首次执行和修订归入同一操作。

已确定
字段 类型 可空 默认值 业务含义 约束
id TEXT 否 无 本次命令执行的唯一标识。 唯一。
operation_id TEXT 否 无 同一次操作的标识，关联首次执行与修订。 同组会话与 type 一致；同组最多一条非终态记录。
session_id TEXT 否 无 命令所属的会话。 外键 sessions.id，级联删除。
run_id TEXT 是 NULL 本次命令关联的 Run。 外键 runs.id，会话须一致；独立操作为 NULL。
seq INTEGER 否 无 本次执行在会话中的创建顺序。 与 messages.seq 在会话内共同唯一，创建后不变。
type TEXT 否 无 辅助命令的业务类型。 rename / polish / handoff / compact / commit / suggest。
status TEXT 否 'pending' 本次命令执行的状态。 pending / running / cancelling / done / failed / interrupted / cancelled。
input TEXT 否 无 本次命令的业务输入。 合法 JSON，无参数时为 {}。首次润色保存 text，修订保存 base_id、feedback。
result TEXT 是 NULL 本次执行成功后的业务结果。 合法 JSON。交接保存标题及文稿，压缩保存摘要引用、标题、压缩前后 Token 数和当时的窗口上限，Git 提交保存已确认的哈希、说明与业务结果。rename 保存 title，suggest 保存 requests。写回依据过期时执行记 cancelled，结果为 SQL NULL。压缩结果引用摘要消息。
error TEXT 是 NULL 执行失败的原因。 JSON 对象 {code, message}。
created_at INTEGER 否 无 本次执行的创建时间。 —

checkpoints

会话检查点

一行保存一个检查点，快照正文直接存入数据库。

已确定
字段 类型 可空 默认值 业务含义 约束
session_id TEXT 否 无 检查点所属的会话。 外键 sessions.id，级联删除。
run_id TEXT 是 NULL 回退至哪个 Run 开始前。 非空时同会话内唯一；空值表示返回快照，每会话最多一行。不建立 Run 外键。
snapshot TEXT 否 无 该检查点的完整恢复数据。 JSON 对象，含会话标题、计划、消息、Run、命令及 agent 凭据，项目文稿文件、可为 null 的主题 ID、四项装饰位置、Logo 字节。普通检查点另含原始输入正文、引用、最初的模型名、模式及范围。文本文件用 JSON 字符串，二进制内容用 Base64。

receipts

请求处理凭据

一行记录一次成功受理或提交的凭据。

已确定
字段 类型 可空 默认值 业务含义 约束
type TEXT 否 无 需要识别重复提交的操作类别。 create_run / create_command / agent / manual。
owner_id TEXT 否 无 本次受理或文件提交所属的会话、Run 或项目。 create_run / create_command 用会话 ID，agent 用 Run ID，manual 用项目 ID。
request_id TEXT 否 无 一次请求的稳定提交标识。 create_run 用初始消息的稳定提交标识，agent 用所属 Run 内的 tool_call_id，manual 用后端操作 ID。与 type、owner_id 组合唯一。
request_hash TEXT 否 无 原始业务参数的摘要。 按规范化的原始业务参数计算。同一请求标识对应的参数摘要须一致。
result TEXT 是 NULL 成功受理后关联的业务记录。 create_run 为 {run_id}；create_command 为 {id}；agent / manual 为 SQL NULL。

assets

资产

一行对应一个主题、组件、技能或文本片段，保存身份、管理信息与正文。

已确定
字段 类型 可空 默认值 业务含义 约束
id TEXT 否 无 资产的稳定标识。 全资产库唯一。
type TEXT 否 无 资产所属类别。 theme / component / skill / snippet；创建后不变。
name TEXT 否 无 资产列表、选择器与搜索使用的名称。 非空，最多 80 字符。同一类型内名称按原名称精确比较，必须唯一。
description TEXT 否 无 供界面展示、搜索与 Agent 选择的简介。 非空，最多 500 字符。
content TEXT 否 无 资产的完整正文。 直接保存原文：主题为 CSS，组件为 HTML，技能为 Markdown，短语为纯文本。
enabled INTEGER 否 1 是否启用该资产。 1 为启用，0 为停用。主题被项目引用时禁止停用。
updated_at INTEGER 否 无 资产最后更新时间，毫秒时间戳，供资产列表、选择器及短语候选统一排序。 每次成功更新资产均递增，包括同值保存。

tags

标签

一行对应一个标签，保存适用类别与显示名称。

已确定
字段 类型 可空 默认值 业务含义 约束
id TEXT 否 无 标签的稳定标识。 全标签库唯一。
type TEXT 否 无 允许使用该标签的资产类别。 theme / component / skill / snippet；不得跨类别关联。
name TEXT 否 无 标签展示名称，如“极简”。 非空；同一 type 内按原名称保持唯一。

asset_tags

资产标签关联

一行表示某个资产使用了某个标签。

已确定
字段 类型 可空 默认值 业务含义 约束
asset_id TEXT 否 无 使用标签的资产。 外键关联 assets.id，随资产删除。
tag_id TEXT 否 无 资产使用的标签。 外键关联 tags.id，随标签删除；组合唯一，两侧 type 须一致。

settings_fileopen

文件打开设置

保存应用全局的文件打开方式与自定义应用列表。

已确定
字段 类型 可空 默认值 业务含义 约束
id INTEGER 否 1 唯一的文件设置记录。 固定为 1，全表一行。
default_open TEXT 否 'system' 文件的默认打开方式。 system 或 custom_apps 中的应用绝对路径。
json_open TEXT 否 'inherit' JSON 文件的打开方式。 取值同 default_open，另允许 inherit 表示继承。
html_open TEXT 否 'inherit' HTML 文件的打开方式。 取值同 json_open。
custom_apps TEXT 否 '[]' 用户添加到选项中的应用。 规范化的应用绝对路径 JSON 数组。Windows 使用 .exe，其他平台使用 .app，按首次出现顺序去重。

settings_shortcut

快捷键设置

保存应用全局的快捷键与输入触发符，每个操作对应一个独立字段。

已确定
字段 类型 可空 默认值 业务含义 约束
id INTEGER 否 1 唯一的快捷键设置记录。 固定为 1，全表一行。
command_trigger TEXT 否 '/' 打开命令菜单的输入触发符。 单个支持的标点符号；五种触发符不得重复。
reference_trigger TEXT 否 '@' 打开综合引用菜单的输入触发符。 同 command_trigger。
component_trigger TEXT 否 '$' 引用组件的输入触发符。 同 command_trigger。
slide_trigger TEXT 否 '#' 引用幻灯片的输入触发符。 同 command_trigger。
snippet_trigger TEXT 否 '%' 插入短语的输入触发符。 同 command_trigger。
previous_slide TEXT 否 'Primary+ArrowLeft' 切换到上一张幻灯片的快捷键。 Primary、Option 或 Alt 中的一个修饰键与一个普通键用 + 连接。组合需避开保留键且互不重复。
next_slide TEXT 否 'Primary+ArrowRight' 切换到下一张幻灯片的快捷键。 同 previous_slide。
zoom_in TEXT 否 'Primary+Equal' 放大演示文稿的快捷键。 同 previous_slide。
zoom_out TEXT 否 'Primary+Minus' 缩小演示文稿的快捷键。 同 previous_slide。
toggle_overview TEXT 否 'Primary+KeyO' 切换总览的快捷键。 同 previous_slide。
export_deck TEXT 否 'Primary+KeyP' 导出演示文稿的快捷键。 同 previous_slide。
toggle_view TEXT 否 'Primary+KeyU' 切换视图的快捷键。 同 previous_slide。
toggle_source TEXT 否 'Primary+KeyI' 切换 HTML 预览与源码的快捷键。 同 previous_slide。
switch_theme TEXT 否 'Primary+KeyT' 切换主题的快捷键。 同 previous_slide。
submit_request TEXT 否 'Primary+Enter' 提交输入框请求的快捷键。 同 previous_slide。
select_suggestion TEXT 否 'Option' 选择建议的共用修饰键前缀。 只存单个修饰键，与数字 1、2、3 分别组合检查冲突。检查时 Option 与 Alt 等价。

settings_models

模型配置

每行保存一套可选用的模型连接配置。

已确定
字段 类型 可空 默认值 业务含义 约束
id TEXT 否 无 稳定的模型配置 ID。 主键，由服务端生成唯一字符串。
name TEXT 否 无 模型配置名称。 全局唯一。
protocol TEXT 否 无 调用模型所使用的 API 协议。 responses / anthropic。
provider TEXT 否 无 用户选择的模型品牌。 deepseek、kimi、mimo、gpt、claude、gemini、qwen、minimax、glm、grok。
base_url TEXT 否 无 模型 API 的基础地址。 非空白字符串，保存规范化后的模型基础地址。
model TEXT 否 无 实际请求的模型标识。 非空字符串。
key TEXT 否 无 调用模型所需的密钥。 非空且不能仅含空白字符。

settings_route

模型选择

保存主路、旁路及各旁路用途的模型选择。

已确定
字段 类型 可空 默认值 业务含义 约束
id INTEGER 否 1 唯一的模型选择设置记录。 固定为 1，全表一行。
main_default TEXT 否 无 主路默认模型配置。 外键 settings_models.id。
main_fallback TEXT 是 NULL 主路备用模型配置。 外键关联 settings_models.id；为空表示不启用备用。
side_default TEXT 否 无 旁路默认模型配置。 外键 settings_models.id。
side_fallback TEXT 是 NULL 旁路统一备用模型配置。 外键关联 settings_models.id；为空表示不启用备用。
rename TEXT 是 NULL 会话命名使用的模型配置。 外键关联 settings_models.id；为空时使用 side_default。
compact TEXT 是 NULL 上下文压缩使用的模型配置。 外键关联 settings_models.id；为空时使用 side_default。
commit TEXT 是 NULL 提交说明生成使用的模型配置。 外键关联 settings_models.id；为空时使用 side_default。
polish TEXT 是 NULL 提示词润色使用的模型配置。 外键关联 settings_models.id；为空时使用 side_default。
handoff TEXT 是 NULL 交接说明生成使用的模型配置。 外键关联 settings_models.id；为空时使用 side_default。
suggest TEXT 是 NULL 下一步建议生成使用的模型配置。 外键关联 settings_models.id；为空时使用 side_default。

settings_behavior

智能体设置

自动命名、建议与两项审批开关在 Run 受理时固定；工具失败的展示开关即时生效。

已确定
字段 类型 可空 默认值 业务含义 约束
id INTEGER 否 1 唯一的智能体设置记录。 固定为 1，全表一行。
auto_rename_enabled INTEGER 否 1 是否自动生成和更新会话名称。 0 / 1。
auto_suggest_enabled INTEGER 否 1 是否自动生成下一步建议。 0 / 1。
show_tool_failures INTEGER 否 0 是否在时间线显示工具调用失败。 0 / 1。
require_resource_approval INTEGER 否 0 编辑项目基本信息、全局约束和目录结构是否需要审批。 0 / 1。
require_high_risk_approval INTEGER 否 1 高风险操作是否需要人工审批。 0 / 1。
