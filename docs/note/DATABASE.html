projects

项目

一行对应一个创作项目，保存项目身份、管理名称和项目级设置。

已确定
字段 类型 可空 默认值 业务含义 设计建议
id TEXT 否 无 项目的稳定标识，不随项目重命名变化。 后端生成唯一 ID。
title TEXT 否 无 项目管理名称；与演示文稿内容标题独立。 允许项目同名；重命名不修改演示文稿标题。
theme TEXT 否 无 当前选中的主题 ID；不保存主题 CSS。 外键关联 assets.id；写入时校验 assets.kind = 'theme'。
logo BLOB 是 NULL 当前 Logo 的图片文件二进制内容。 只保存图片二进制，不保存原始文件名；后缀、MIME、尺寸与哈希按需计算。
slide_pagination_position TEXT 否 'bottom-right' 页码的显示位置；none 表示关闭。 位置可选上／下 × 左／中／右，关闭用 none；四项启用位置不得重复。
deck_title_position TEXT 否 'none' 演示文稿标题的显示位置；不保存标题文字。 与页码使用相同的位置枚举和互斥规则。
section_title_position TEXT 否 'top-left' 章节标题的显示位置；不保存章节名称。 与页码使用相同的位置枚举和互斥规则。
project_logo_position TEXT 否 'none' Logo 的显示位置；与图片是否已上传分别保存。 与页码使用相同的位置枚举和互斥规则；关闭显示不删除图片。
created_at INTEGER 否 无 项目的创建时间。 由后端在创建项目时写入，此后不变。
updated_at INTEGER 否 无 项目更新标记，供项目列表排序及显示。 由后端维护。

sessions

会话

一行对应项目中的一个会话，保存会话身份、名称、所属项目和当前计划。

已确定
字段 类型 可空 默认值 业务含义 设计建议
id TEXT 否 无 会话的唯一标识。 后端生成唯一 ID。
project_id TEXT 否 无 会话所属的项目。 外键关联 projects.id，随项目删除；为按项目查询建立索引。
revision INTEGER 否 0 当前会话的统一提交版本。 事务内递增并赋给变更的业务记录；用于同步和过期操作校验，回退时保持递增。
title TEXT 否 '新会话' 会话名称。 允许会话同名；自动命名统一由全局设置控制，手动改名后仍可自动覆盖。
plan TEXT 是 NULL 会话当前生效的执行计划。 JSON 对象 {run_id, steps}；步骤保存标题和状态，清除时置空，版本沿用会话。
created_at INTEGER 否 无 会话的创建时间。 由后端维护。
updated_at INTEGER 否 无 会话的更新时间。 由后端维护。

runs

执行任务

一行对应一次 Agent 任务；等待回答或审批沿用当前 Run，任务结束后重新发起新 Run。

已确定
字段 类型 可空 默认值 业务含义 设计建议
id TEXT 否 无 任务的唯一标识。 后端生成；任务结束后不恢复。
session_id TEXT 否 无 任务所属的会话。 外键关联 sessions.id，随会话删除；建立索引。
project_id TEXT 否 无 任务操作的项目。 外键关联 projects.id；校验会话归属，非终态任务按项目唯一。
revision INTEGER 否 无 任务状态最近一次提交的版本。 使用会话提交序号；同一事务只发布最终状态，兼作同步位置与并发校验值。
mode TEXT 否 无 当前执行模式。 chat / ask / plan / create。
model TEXT 否 无 任务选择的模型配置名。 启动时读取该配置；不保存供应商、模型名称和地址快照。
scope TEXT 是 NULL 当前允许操作的页面 ID 列表。 NULL 不限本项目页面；JSON 数组限定页面 ID，章节提交时展开，[] 不授权任何页面。仅经范围审批变更。
status TEXT 否 'pending' 任务的执行状态与结束结果。 pending / running / waiting / cancelling / done / rejected / failed / interrupted / cancelled；waiting、cancelling 仍占用项目。
changes TEXT 是 NULL 任务结束时冻结的净修改差异。 JSON 数组，保存目标、变更类别与差异；[] 表示无净变化，NULL 表示尚未生成或不可用。
error TEXT 是 NULL 导致整个任务失败的具体错误。 JSON 对象 {code, message}；无对应错误时为空。
input_tokens INTEGER 否 0 累计已报告的输入 Token 数。 非负整数；按模型调用去重累计。
output_tokens INTEGER 否 0 累计已报告的输出 Token 数。 非负整数；按模型调用去重累计。
total_tokens INTEGER 否 0 累计已报告的总 Token 数。 保留供应商报告的总量。
call_count INTEGER 否 0 累计模型调用次数。 非负整数；包含未报告 Token 用量的调用。
active_duration INTEGER 否 0 已累计的有效执行时长。 排除等待回答和审批时间；新任务重新计时。
active_since INTEGER 是 NULL 当前有效计时段的起点。 与累计时长共同驱动计时；停止计时时清空。
created_at INTEGER 否 无 任务的创建时间。 由后端维护。
updated_at INTEGER 否 无 任务的更新时间。 由后端维护。

messages

消息

一行对应一条消息，统一保存正文、引用和用户输入处理状态。

已确定
字段 类型 可空 默认值 业务含义 设计建议
id TEXT 否 无 消息的唯一标识。 用户消息沿用提交时的 ID，重试复用；其他消息由后端生成。
session_id TEXT 否 无 消息所属的会话。 外键关联 sessions.id，随会话删除。
run_id TEXT 是 NULL 消息所属的执行任务。 外键关联 runs.id，校验会话一致；会话级手动压缩摘要可为空。
revision INTEGER 否 无 消息记录最近一次提交的版本。 使用会话提交序号；处理状态等更新时递增，正文与原始引用不覆盖。
seq INTEGER 否 无 消息在会话中的固定顺序。 与旁路命令共用会话序号分配，创建后不变；同事务内不同记录也使用不同序号。
kind TEXT 否 无 消息的业务用途。 instruction / response / thinking / commentary / tool_call / tool_result / summary；每个 Run 最多一条 response。
content TEXT 否 无 正文、引用及工具内容。 合法 JSON；instruction 为 {text, references}，引用有序；其余按 kind 保存实际内容。
raw TEXT 是 NULL 后续模型调用要求携带的原生协议数据。 合法 JSON；仅在适配器实际需要时保存，不返回前端。
tool_call_id TEXT 是 NULL 关联工具调用与结果的调用 ID。 tool_call / tool_result 必填，其他类型为 NULL；同一 Run 的同一调用，两种记录各最多一条。
instruction_decision TEXT 是 NULL JEV 对用户输入的分类结果。 仅 instruction 使用：task / chat / disclosure / bypass / irrelevant；未判定或检测失败时为空。
instruction_status TEXT 是 NULL 用户输入的信箱处理状态。 仅 instruction 使用：queued / sent，初始为 queued；其他消息为 NULL。
context_position INTEGER 是 NULL 消息在当前模型上下文中的位置。 非空时同会话唯一；NULL 表示不参与。压缩时重排，聊天历史顺序不变。
created_at INTEGER 否 无 消息创建时间。 由后端写入，用于历史消息时间展示。

commands

旁路命令

一行对应一次辅助命令执行；重试与修订归入同一操作。

已确定
字段 类型 可空 默认值 业务含义 设计建议
id TEXT 否 无 本次命令执行的唯一标识。 重试或修订创建新记录；请求去重由统一请求记录处理。
command_id TEXT 否 无 同一命令及其重试、修订的分组标识。 同组沿用此 ID，校验会话与类型一致；同组最多一条非终态记录。
session_id TEXT 否 无 命令所属的会话。 外键关联 sessions.id，随会话删除；项目由会话取得。
run_id TEXT 是 NULL 本次命令关联的 Run。 外键关联 runs.id，校验会话一致；任务派生或结果依赖某 Run 时填写，独立操作为空。
revision INTEGER 否 无 执行记录最近一次提交的版本。 使用会话提交序号；状态及结果变化时更新。
seq INTEGER 否 无 本次执行在会话中的创建顺序。 与消息共用序号分配；同一 command_id 的卡片使用最早的 seq。
kind TEXT 否 无 辅助命令的业务类型。 rename / polish / handoff / compact / commit / suggest；rename 仅生成标题。
status TEXT 否 'pending' 本次命令执行的状态。 pending / running / cancelling / done / failed / interrupted / cancelled。
input TEXT 否 无 本次命令的业务输入。 合法 JSON，仅保存实际参数，无参数时为 {}；修订保存基础执行 ID 与反馈。
result TEXT 是 NULL 本次执行成功后的业务结果。 合法 JSON；压缩引用摘要消息，交接保存文稿，提交保存 Git 结果。
error TEXT 是 NULL 异常说明及是否允许重试。 合法 JSON，保存 code / message / retryable；供错误展示与重试操作。
created_at INTEGER 否 无 本次执行的创建时间。 由后端写入；每次重试或修订保留自己的时间。

checkpoints

会话检查点

一行保存一个检查点，快照正文直接存入数据库。

已确定
字段 类型 可空 默认值 业务含义 设计建议
session_id TEXT 否 无 检查点所属的会话。 外键关联 sessions.id，随会话删除；同一会话可保存多个检查点。
run_id TEXT 是 NULL 回退至哪个 Run 开始前。 非空时同会话内唯一；空值表示返回快照，每会话最多一行。不建立 Run 外键。

receipts

请求处理凭据

一行记录一次成功受理或提交的凭据。

已确定
字段 类型 可空 默认值 业务含义 设计建议
kind TEXT 否 无 需要识别重复提交的操作类别。 create_run / create_command / commit_files。
owner_id TEXT 否 无 请求所属的会话或 Run。 创建 Run、受理命令用会话 ID；文件提交用 Run ID。
request_id TEXT 否 无 一次请求的稳定提交标识。 重复提交复用；与 kind、owner_id 组合唯一。
request_hash TEXT 否 无 原始业务参数的摘要。 对规范化参数计算；同一请求标识携带不同参数时拒绝。
result TEXT 是 NULL 成功受理后关联的业务记录。 创建 Run/命令保存目标记录 ID 的 JSON；文件提交为 NULL。

assets

资产

一行对应一个主题、组件、技能或文本片段，保存身份、管理信息与正文。

已确定
字段 类型 可空 默认值 业务含义 设计建议
id TEXT 否 无 资产的稳定标识。 全资产库唯一；用于引用、查询与更新资产。
kind TEXT 否 无 资产所属类别。 theme / component / skill / snippet；创建后不变。
name TEXT 否 无 资产列表、选择器与搜索使用的名称。 非空，最多 80 字符；snippet 名称不区分大小写唯一。
description TEXT 否 无 供界面展示、搜索与 Agent 选择的简介。 非空，最多 500 字符。
content TEXT 否 无 资产的完整正文。 直接保存原文：主题为 CSS，组件为 HTML，技能为 Markdown，短语为纯文本。
disabled INTEGER 否 0 是否停用该资产。 0 / 1；停用后仍可管理，不再供选择或 Agent 加载。

fileopen

文件打开设置

保存应用全局的文件打开方式与自定义应用列表。

已确定
字段 类型 可空 默认值 业务含义 设计建议
id INTEGER 否 1 唯一的文件设置记录。 固定为 1，全表一行。

shortcuts

快捷键设置

保存应用全局的快捷键与输入触发符，每个操作对应一个独立字段。

已确定
字段 类型 可空 默认值 业务含义 设计建议
id INTEGER 否 1 唯一的快捷键设置记录。 固定为 1，全表一行。
command_trigger TEXT 否 '/' 打开命令菜单的输入触发符。 单个支持的标点符号；五种触发符不得重复。
reference_trigger TEXT 否 '@' 打开综合引用菜单的输入触发符。 单个支持的标点符号。
component_trigger TEXT 否 '$' 引用组件的输入触发符。 单个支持的标点符号。
page_trigger TEXT 否 '#' 引用页面的输入触发符。 单个支持的标点符号。
snippet_trigger TEXT 否 '%' 插入短语的输入触发符。 单个支持的标点符号。
previous_page TEXT 否 'Primary+ArrowLeft' 切换到上一页的快捷键。 普通字符串；Primary 对应 Command／Ctrl。
next_page TEXT 否 'Primary+ArrowRight' 切换到下一页的快捷键。 修饰键与按键代码用 + 连接。
zoom_in TEXT 否 'Primary+Equal' 放大演示文稿的快捷键。 按键保存 Equal 等代码。
zoom_out TEXT 否 'Primary+Minus' 缩小演示文稿的快捷键。 按键保存 Minus 等代码。
toggle_overview TEXT 否 'Primary+KeyO' 切换总览的快捷键。 组合键须通过按键与冲突校验。
export_deck TEXT 否 'Primary+KeyP' 导出演示文稿的快捷键。 组合键须通过按键与冲突校验。
toggle_view TEXT 否 'Primary+KeyU' 切换视图的快捷键。 组合键须通过按键与冲突校验。
toggle_source TEXT 否 'Primary+KeyI' 切换 HTML 预览与源码的快捷键。 组合键须通过按键与冲突校验。
switch_theme TEXT 否 'Primary+KeyT' 切换主题的快捷键。 组合键须通过按键与冲突校验。
submit_request TEXT 否 'Primary+Enter' 提交输入框请求的快捷键。 组合键须通过按键与冲突校验。
suggestion_1 TEXT 否 'Alt+Digit1' 填入第 1 条建议的快捷键。 Alt 对应 Option／Alt。
suggestion_2 TEXT 否 'Alt+Digit2' 填入第 2 条建议的快捷键。 组合键须通过按键与冲突校验。
suggestion_3 TEXT 否 'Alt+Digit3' 填入第 3 条建议的快捷键。 组合键须通过按键与冲突校验。
