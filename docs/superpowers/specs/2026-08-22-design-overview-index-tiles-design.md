# 设计稿概览索引板

## 适用范围

本设计调整 `PreviewWorkspace` 中“设计稿 + 概览视图”的页面网格，不改变单页设计稿、HTML 幻灯片预览、数据契约或页面选择逻辑。

## 背景

原概览将外层 `OverviewSlide` 与紧凑 `SlideSpecCard` 叠加。两层均有白底、圆角、边框和阴影，且紧凑卡仍同时容纳角色、标题、核心信息和页码。16:9 的小型网格无法稳定承载这些内容，长标题会挤压并截断信息。

## 决策

- 概览定位为页面索引板，用于快速确认页序、页面角色和主题，不承担完整设计稿阅读任务。
- 每格只保留一层卡片表面：页序、角色和最多两行标题。
- 页序显示为左上角两位编号，角色使用无底色的低强调文字；不再使用深色页码胶囊或蓝色角色标签。
- 移除概览中的核心信息、元素列表、物化状态和内部滚动；这些信息保留在单页设计稿。
- 选中状态是唯一的蓝色强调：外层卡片蓝色描边。
- 全局视觉规范在概览中收束为一行主题/密度元数据，设计方向和装饰规则通过详情按需展开。

## 非目标

- 不修改 HTML 缩略图概览的渲染或惰性加载策略。
- 不改变页面点击后返回单页预览的行为。
- 不改变 `SlideSpecCard` 的单页设计稿信息密度。

## 验收标准

1. 设计稿概览卡片不再嵌套 `SlideSpecCard` 或出现双重边框/阴影。
2. 每张设计稿卡片仅显示页序、中文角色和两行以内标题。
3. 概览中不展示核心信息和元素 intent，长标题不会推动卡片内容溢出。
4. 当前页仍有明确的蓝色选中描边；点击卡片仍进入该页。
5. 全局视觉规范默认不占用一张独立卡片，详情仍可展开。
