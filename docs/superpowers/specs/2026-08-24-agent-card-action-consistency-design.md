# Agent 卡片操作一致性设计

## 目标

统一计划审批卡片与询问卡片的主操作表达，并将已回答询问的摘要恢复为常规字重。

## 交互与视觉

- 计划审批卡片在可提交时使用黑色主按钮，内容为右箭头图标加「继续」。
- 用户点击后，按钮保持既有的禁用逻辑，加载文案为「提交中」。
- 未选择审批项、或「返回修改」尚未填写意见时，按钮仍不可用。
- 已回答询问的父级摘要「询问了 n 个问题」移除 `font-medium`，与相邻时间线文本保持一致。

## 范围与验证

仅修改 `PlanApproval` 与 `QuestionPanel` 的前端呈现；不变更审批请求、状态管理或事件协议。更新相关组件测试，验证默认、禁用和请求中按钮文案，以及问题摘要的常规字重。
