# ADR-0011：安全姿态（单机自用工具）

## 背景

产品定位为**单机自用、无登录注册**的高完成度工具。需明确"哪些安全不做、哪些必须做"，避免过度设计（安全剧场），也避免漏掉会咬到自己的正确性护栏。

## 决策

### 明确不做（与定位一致）
- 用户级权限 / RBAC / 多租户隔离（无登录，天然不需要）。
- 网络攻击面防护：后端默认仅监听 `127.0.0.1`（`ARCH-SYS-006`），不暴露公网。
- slide 产出的 XSS / 内容消毒（自己生成给自己看）。
- 资产远程加载安全审查（MVP 仅本地信任，`ASSET-008`）。

### 必须保留（正确性护栏，非安全剧场）
- **工具路径边界**（`ARCH-TOOLS-006`）：所有工具文件读写限定在当前 project work_dir 或 `_assets/` 内，防 LLM 生成异常路径（`../../../`）写坏本机其它文件。
- **预览 iframe sandbox**（`ARCH-PREVIEW-001`）：本就是预览机制一部分，防生成的 JS 逃逸操作宿主页面，零额外成本。

## 选项与权衡

| 选项 | 优点 | 缺点 |
|---|---|---|
| 跳过企业级 + 保留两条护栏（选中） | 不过度设计、成本极低、守住正确性边界 | 不适用于未来多用户/公网部署（需另做） |
| 全套企业级安全 | 面向公网就绪 | 与单机定位不符，过度设计 |
| 完全不做任何边界 | 最省事 | LLM 坏路径可能损坏本机文件 |

## 后果

- `ARCH-TOOLS-006` 与其验收 `AC-TOOLS-006` 落地路径边界。
- iframe sandbox 已在 `ARCH-PREVIEW-001`。
- 未来若转向多用户/公网部署，需新开 ADR 补鉴权、网络与内容安全（当前明确不在范围）。
