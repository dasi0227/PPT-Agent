模式入口

图标与名称常驻。点击任意方案的模式按钮，体验四种模式切换。

A

上方独立按钮

推荐

模式先于输入出现，独立于附件、技能等辅助工具。

最均衡。位置醒目，输入框内部完整；需要一行额外高度。

B

输入框内顶部

模式成为输入内容的前置设置，整体归属更明确。

更集中。只有一个输入容器；模式入口会占用部分内部高度。

C

贴边模式标签

标签与输入框连为一体，直接表达“当前输入模式”。

关联最强。轮廓更有辨识度，但比独立按钮多一点视觉结构。

D

独立模式说明行

名称与行为说明一起常驻，减少选错模式的可能。

含义最清楚。适合强调只读与开发的区别；常驻信息相对更多。
