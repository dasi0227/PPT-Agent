把注释和标记的关系说清楚

三种局部方案。保留主输入框作为尺寸参照，只比较标记的编辑与收起方式。

A · 锚定浮层 推荐

点击标记，在它上方编辑。输入区保持原有高度。

改动最少。标题明确“标记 1 · 注释”，浮层与标记之间有锚点。移除按钮始终留在标记上。

B · 标记内展开

标记和注释共用一个容器，上下归属最直接。

最好理解。不遮挡上方内容；编辑时会撑高输入区，多个标记时需要更多纵向空间。

C · 共用编辑区

上方切换标记，下方始终只编辑当前标记的注释。

适合多个标记。编辑宽度稳定、切换顺手；与主输入框相邻，需要保留明确的标记标题。

可直接输入、切换标记、收起与移除。点击外部或 Esc 保留注释并收起；⌘ / Ctrl + Enter 返回主输入框。每条最多 500 字。此页仅演示交互，刷新后重置。B、C 是对原“标记上方注释框”约定的替代提案。
