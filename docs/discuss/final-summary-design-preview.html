点击跳转怎么做

  • 应用内跳转：事件 target 带 slide_id 和 part。
  • 点行或跳转按钮时：setCurrentPage(index)，再按 part 设置 outline/html。
  • 这应该是产品主路径，因为它不离开当前 App。

能不能默认 VS Code 打开

浏览器网页不能强制指定默认用 VS Code 打开。可以提供 vscode://file/绝对路径:行:列 深链；如果用户本机注册了 VS Code 协议，浏览器会询问并打开。更强制的方式需要本地后端提供 “open in editor” 接口并执行 code -g，但这只适合本地开发模式，不能默认面向普通产品用户。

变更标记 icon 候选（lucide-react）

预览名称语义建议
Sparkle 单个四角星，最接近当前视觉。 已选
Sparkles 更像生成/魔法感，略活泼。 可选

跳转页面 icon 候选（lucide-react）

预览名称语义建议
ArrowRight 进入应用内目标页；最朴素。 可选
ExternalLink 跳转感最强，但容易和外部打开混淆。 不推荐用于应用内跳转
LocateFixed 定位到当前页面/目标资源，语义准确。 可选
Crosshair 瞄准镜/准星，定位感最强。 已选
Focus 聚焦目标，视觉更克制。 可选

打开文件 icon 候选（lucide-react）

预览名称语义建议
ExternalLink 打开到外部应用/编辑器，通用且清晰。 已选
FileCode2 打开源码文件，开发者语义更强。 可选
Code2 强调代码，但不像“打开”。 不推荐单独使用
