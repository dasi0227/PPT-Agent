等待回答时使用特殊问题框；选择题最多 3 个给定选项，允许自定义时额外显示“自定义回答”；长描述按行数截断，悬浮展示完整内容。

把询问组件改成支持多个问题连问，并且不要把多个选择题糅合成一个开放问答。

我需要先盘问 3 个问题。

有明确选项时，题型如何处理？

固定为单选题，且这里是比较固定的答案，因此不提供自定义输入。题目描述最多显示三行，超过后截断，避免问题框被长文本撑开。

如果选项可能不完整，如何允许用户补充？

仍然是单选题，但可以开启自定义输入。用户可选一个给定答案，也可以输入自己的答案。

还有哪些必须遵守的展示约束？

没有明确选项，所以不渲染为选择题，而是独立填空题。

联调口径

  • 等待态不展示额外的问题组标题，直接展示当前问题。
  • questions[] 承载多个原子问题，每题含 title / description。
  • 有 options 的问题固定单选，不再暴露多选默认路径。
  • 选择题最多 3 个给定选项；若允许自定义，额外显示 1 个“自定义回答”。
  • 单选题可按需设置 allow_custom=true，只增加自定义输入，不改变单选语义。
  • 固定答案场景使用 allow_custom=false，不显示自定义输入。
  • 无 options 的问题固定填空。
  • 题目 description 最多 3 行；选项 description 最多 2 行，超出后悬浮展示完整内容。
  • 等待回答：特殊组件框，图标闪烁绿色。
  • 提交回答：普通时间线行，父行文案为“询问了 x 个问题”。
  • 多问题回答：组内每题一行，格式为 Q： / A：。
  • 后端需同步完善 ask_user 工具定义与系统提示词，约束多问题拆分、选项上限、allow_custom 语义和提交校验。
