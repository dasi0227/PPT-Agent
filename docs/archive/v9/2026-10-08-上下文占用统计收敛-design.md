# 上下文占用统计收敛

日期：2026-10-08。状态：实现完成；功能与界面由用户手动验收。

## 分类与估算

| 分类 | 明细 |
| --- | --- |
| 系统提示词 | system prompts、tool definitions |
| 运行时 | runtime context、runtime messages |
| 历史记录 | user messages、assistant messages、tools execution |
| 读取 | read_resource、read_image |
| 其它 | other |

- runtime context 合并原运行状态与运行资源；历史摘要计入 runtime messages，保留实际压缩摘要机制。
- 命令调用及结果归入 tools execution，取消命令单独分类与命令排名。
- 逐内容块分类：所有实际送入模型的图片进入 read_image，包括上传、读取、渲染和压缩后恢复的图片；render_slide 的调用与文本诊断仍进入 tools execution。
- read_resource 只计算当前上下文中保留的调用及文本结果。被摘要替代后可以为零，不代表从未读取资源。
- 文本沿用 Unicode 字符粗估：空文本为 0，否则 `(字符数 + 2) / 3 + 1`，除法取整数；图片每块固定 1024。消息协议包装计入其它。
- 工具定义按 Provider 的模型可见投影计量，输出契约只计一次。取消实际 input usage 对所有分类的比例校准，不引入 tokenizer。
- 明细相加等于分类，分类相加等于总量。统计表示粗估占用，不声称与 Provider 的实际 token 一致。

## 快照更新

仅在以下边界重新计算：模型请求前、Run 结束（成功、失败、取消）、压缩后、后端重启后的首次读取。暂停后取消等未进入正常 Runtime 收尾的路径同样刷新。

普通查询返回内存快照；打开面板只读取，不额外重算。不以模型标识、资源指纹或图片哈希判定快照失效；模型配置仍提供窗口容量。

首次读取与手动压缩从原始消息和最新 Run 检查点组装完整请求上下文，包含系统提示词、工具定义、运行时模块及当前图片集合。不恢复旧 token 总数，也不通过减去旧历史、加上新历史修补快照。图片自身的既有保留与有效性规则继续使用。

前端终态读取服务端最新快照；较早发出的 HTTP 查询不得覆盖其间收到的新快照。历史消息存储保留原始角色、内容及元数据，分类只在统计时计算。

后端服务构建、TypeScript 类型检查通过；contextengine、model、service、workflow、run 的测试源码编译通过。未执行测试用例、真实模型请求或浏览器验证。已补充图片归属、Run 收尾、暂停取消、重启重建和 HTTP/SSE 竞态的定向用例，供后续手动运行。

## 手动验收

- 查看首次打开和后端重启后的空任务、已有任务，系统提示词与运行时应完整计入。
- 读取资源、运行命令、渲染页面并上传图片，确认分类与明细归属；Run 最终回复应进入结束快照。
- 执行自动和手动压缩，确认摘要进入运行时消息，系统提示词不随历史压缩比例缩小，图片归属保持一致。
- 成功、失败、运行中取消、暂停后取消分别检查结束快照；普通重复查询不触发重新估算。
