# 工作区面板控制与项目创建确认

## 目标

恢复工作区左右栏的稳定控制入口，并移除面向用户的“新建中”占位项目状态。

## 面板控制

- 左右栏继续使用现有的可伸缩面板实现和本地持久化策略。
- 控制按钮固定在顶部项目栏右侧，不随任一侧栏隐藏而消失。
- 收起状态显示对应的展开图标，展开状态显示对应的收起图标。
- 预览工具栏内现有的恢复按钮保留为快捷入口。

## 项目创建

- 点击 `+` 仍先展示“新建项目 / 打开已有项目”选择。
- 选择“新建项目”后，在同一弹窗内输入项目名称并明确确认。
- 仅在用户确认后调用既有的项目创建接口。提交期间禁用创建动作以防重复提交。
- 成功后才把真实项目加入并选中；不创建 `new-pending`、不展示“新建中…”。
- 失败时保留名称和弹窗，在输入框下显示错误并允许重试。
- 创建完成后的右侧输入框只提交项目内生成指令，不再隐式创建项目。

## 边界

- 不修改后端实现、API 路径、请求格式或前后端协议。
- 不改动现有左右栏的拖拽伸缩范围与持久化 key。
