# 提问正文命名与句式

日期：2026-10-01。状态：已实施，待用户手动验收。

## 工具协议

`ask_user` 输入的问题正文由 `questions[].title` 改为必填的 `questions[].question`。顶层 `questions` 表示问题集合，内层 `question` 表示直接展示给用户的问题正文。

实际 Tool Definition 的 description 要求问题包含回答所需上下文，使用完整疑问句，以 `?` 或 `？` 结尾，禁止分类标题、陈述句和指令句。句式和问号仅通过 description 引导模型，前后端不增加相关校验，保留原有非空字符串和结构校验。

## 前后端同步

公共事件 `question.asked` 的 `questions[]`、后端检查点中的待回答问题、前端类型与事件解析、问题展示、等待状态摘要和历史恢复统一使用 `question`。模型回答输出 `answers[].question` 返回原输入的 `questions[].question` 文本。

直接切换新字段，不保留 `title` 兼容分支，不迁移历史开发数据。问题与选项 ID、选择和自定义回答、逐题跳过及挂起恢复流程保持现有行为。

## 手动验收

- 发起真实模型提问，确认工具参数使用 `question`，问题正文为以问号结尾的完整疑问句。
- 多题切换、逐题跳过、选择预设选项和自定义回答后，确认模型收到原问题正文及对应答案。
- 刷新待回答的问题或重新打开本次新协议历史，确认问题正文和等待状态正常恢复。
