# 单次工具编辑差异展示

日期：2026-10-01。状态：已实施，待用户手动验收。

## 1. 范围与展示

将 [最终变更总结](2026-10-01-final-change-summary-design.md) 的共享差异卡片用于 `edit_manifest`、`edit_design`、`edit_spec`、`edit_outline`、`edit_html` 的单次成功编辑。受限 `run_command` 保存文件时也携带对应差异，并保留命令内容和执行输出。本决定替代前文中「单次工具调用继续沿用现有展示」的范围限制。

工具行只显示编辑对象与展开箭头，详情默认折叠。绿色 `+N`、红色 `−N` 放在差异卡片的文件名旁边，单个和多个文件均按各文件计数，右侧保留预览操作。展开后，JSON 显示字段名称、集中排列的删除与新增项及字段分隔线；HTML 显示统一差异块和新旧行号，隐藏 `@@`，每个区块前后保留三行上下文，区块间省略的未修改行通过浅色分隔带展开及收起。省略内容使用事件中冻结的 `context_before[]`，不读取当前文件或计入增删数量。内容不自动折行，支持隐藏滚动条的内部水平滚动，并复用长内容展开控件。

一次工具调用产生多个业务目标时，详情分别展示各目标的差异；大纲删除页面时覆盖同步删除的设计稿和 HTML。工具行不汇总计数，各文件卡片独立展示自身的语义字段或文本行计数。无语义变化且 `changes` 为空的成功编辑不展示差异卡片或当前文件源码。失败、阻止执行或解析失败不伪造成功编辑统计。

读取工具继续展示所读资源；预览操作打开当前文档，历史差异内容始终来自保存的事件。

`edit_outline` 使用已确认的 [目录结构树形差异](2026-10-01-outline-change-summary-design.md)，按章节分组并保留子章节层级、淡色未变化节点和红绿变更行，不沿用普通 JSON 字段列表。目录计数来自各卡片的可见变更行。

## 2. 单次事务边界

复用 `RunSession` 当前工具事务的 `BeforeContent`、`AfterContent`、`Existed`、`Delete`，在提交清空事务之前生成 `OperationTargets`。只比较本次实际暂存的创作文件，排除运行产物、Git 内部文件及历史版本。未变化的大纲仅用于确定当时页序；`.spec.json` 仍按页面 ID 拆分。

同一文件连续编辑 A → B → C 时，两次工具差异分别为 A → B 和 B → C；最终总结为 A → C。恢复原值的工具调用仍显示本次实际变化，最终净变化可以为空。

生成参考校验成功后，将差异与工具结果一起写入操作回执，只有提交成功才发布。提交失败会丢弃该次成功投影并沿用失败状态。幂等重放恢复已保存差异和命令投影，不读取后来文件重新生成内容；中断恢复可按原调用 ID 补发已提交操作的完成事件。

## 3. 公共事件与前端状态

成功资源编辑的 `tool.completed` 增加必需的 `changes: PublicTarget[]`；无变化时为 `[]`。写命令完成时携带该数组；读取、渲染、加载及失败事件不携带。数组各项必须具有已冻结的 `diff`，结构和统计语义沿用最终总结。

`target` 保留主编辑对象的名称、身份和计数，完整差异仅在 `changes` 中保存一次。前后端同步校验数组、目标类型、差异值和行号，不提供旧协议回退或历史数据迁移。

Timeline reducer 持久保留 `changes`，晚到的开始事件不会覆盖已完成编辑的差异和名称。共享 `ChangeStats` 与 `ChangeDiffCard` 统一工具详情及最终总结的颜色、计数和布局。文件保存事件触发项目内容刷新，使预览使用更新后的文档状态。

`OperationTargets` 为内部 UI 投影，不进入模型工具观察，不增加工具输入参数或模型输出字段。

## 4. 手动验收

遵循项目规则，未运行自动测试、构建或浏览器验证；同步现有用例，补充事务边界、回执重放、事件校验和折叠展示的回归用例。

- 连续修改同一 JSON 标题或数组：各工具条目具有本次计数及旧、新值，最终总结仍为任务净变化。
- 连续修改同一 HTML：默认只显示工具摘要，展开后在文件名旁边看到该文件的计数，下方显示该次实际行号和差异。
- 删除大纲页面：展开该次调用，分别看到目录、页面设计稿、HTML 的删除变化。
- 修改后恢复原值：两次工具详情均保留对应操作，最终总结不再列出该净变化。
- 无变化编辑及失败编辑：前者不显示差异卡片，后者保留失败状态且不展示成功差异。
- 使用已批准的 `sed -i` 修改 JSON / HTML：命令输出与差异共同展示，预览使用保存后的内容。
- 完成后再次编辑、重载历史、恢复中断任务：先前工具差异和计数保持不变。
