# 内容要求与固定渲染规则的边界

## 最新决定

`manifest.json` 只保存演示的内容要求：标题、目标、受众、语言、内容要求与禁忌，以及系统维护的版本、项目标识和时间戳。

删除 `positioning`（演示定位），不再独立保存或展示与目标、受众和内容要求重复的信息。

## 新项目初始化

| 字段 | 初始值 | 预览展示 |
| --- | --- | --- |
| `title` | 项目标题 | 项目标题 |
| `goal` | `待明确` | 待明确 |
| `audience` | `待明确` | 待明确 |
| `language` | `待明确` | 待明确 |
| `requirements` | `[]` | 暂无额外要求 |
| `prohibitions` | `[]` | 暂无额外限制 |

初始化不再将项目标题复制为演示目标，也不预设演示语言。Agent 后续根据用户需求和上下文补充实际内容；版本、项目标识和时间戳仍由系统维护。此次调整不重置已有项目的内容。

## 移除渲染配置

移除整个 `canvas` 和 `numbering` 对象，不再提供以下配置：

- `canvas.aspect_ratio`
- `numbering.enabled`
- `numbering.hidden_roles`
- `numbering.format`

这项决定替代此前文档中将画布策略和页码策略归属 Manifest 的约定。

## 固定产品规则

- 画布固定为 1920×1080 CSS px，即 16:9；沿用 Runtime 的规范画布常量。
- 每页显示从目录顺序推导的数字页码，封面、结论等角色不例外。
- `design.decorations.page_number` 控制页码的位置与外观要求；初始化为右下角、空要求，且不允许设置为 `none`。
- Runtime 在幻灯片正文之外绘制页码。前端预览、全屏放映、图片/PDF 导出和离线 HTML 播放器使用同一公共装饰实现。
- 幻灯片作者不在 HTML 正文中写入页码或自行适配画布比例。

## 实现范围

- 同步移除 Manifest 的后端类型、Schema、初始化值、Agent Patch 路径及前端类型和展示。
- Runtime frame 保留规范画布、目录序号、总页数与设计装饰，不再传递页码显隐或格式选项。
- 更新 Agent 提示词，明确这些固定规则不属于 Manifest 的可写内容。
- 直接使用新结构，不增加旧协议兼容分支或历史数据迁移逻辑。
