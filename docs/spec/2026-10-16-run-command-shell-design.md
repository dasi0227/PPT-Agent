# run_command 真实 Shell

## 已确认边界

- 使用真实 Bash，支持管道、重定向、变量、替换、脚本及复合命令；没有读取命令白名单、敏感读取审批、输出大小或命令数量限制。
- 命令在项目副本内执行，没有文件变更时直接返回；所有实际文件变更必须审批，不受高风险审批设置影响。候选文件、原始快照、输出和审批答复持久化，批准或重启恢复均只保存同一候选，不重新执行命令。
- 读取不限制文件范围；写入只能落在隔离项目副本及命令临时目录。系统配置、全局安装、`.git`、`.runtime`、`.run`、`.commit-tmp`、`versions` 仍不可通过命令更改。manifest、design、outline、spec、HTML 和 assets 均可编辑，包括原任务页面范围外的文件；审批仅授权本次具体变更，不扩大后续写入范围。
- 工具只接收 `command`，联网正常可用，不单独申请审批。文件审批只控制本地项目变更；远端影响可能在审批前发生，无法随本地事务回滚。
- 候选文件经过结构、稳定 ID 和页面引用校验；outline 的 `new` ID 和删除页面的关联源码清理在审批前完成，统一展示最终差异。批准后沿现有 RunSession 日志提交；失败、取消、超时或拒绝都不保存本地变更。
- 准备、审批恢复和保存均绑定项目快照；文件、文件权限、目录和符号链接都参与变更与回滚。新符号链接不得越界或指向受保护路径；硬链接和不纳入事务的扩展属性写入被阻止。
- Git commit/push 保持人工入口；显式提交和推送命令被拒绝，仓库内部文件禁止写入，Git 读取命令正常可用。

## 实现

当前桌面产品仅支持 macOS，因此进程写入边界使用系统 Seatbelt（`sandbox-exec`），不提供无沙箱回退。Bash 不加载 profile/rc；子进程使用干净环境，缓存写入隔离临时目录。宿主文件读取遵循系统本身的访问权限。

Shell 的退出码、stdout 和 stderr 原样表达执行结果，退出码非零使用 `COMMAND_EXIT_NONZERO`；包括搜索无匹配时的退出码 1，不另设搜索成功特例。命令或沙箱缺失使用 `COMMAND_NOT_AVAILABLE`，超时使用 `COMMAND_TIMEOUT`。

命令准备期间可产生临时文件，但不会修改真实项目。拒绝写入时返回公共 `status=refuse` 及用户提供的 `feedback`，不返回 `summary`。

## Timeline

命令和审批共用一个工具条目，顶部仅展示命令首行，多行追加省略号。详情按命令输入、命令输出、文件变更排列；每次打开详情，所有分组和文件差异均收起。输出只来自实际 stdout/stderr，不展示模拟流式输出；无输出时省略该组。

文件只展示差异；仅修改显示增删行数，新增/删除不显示行数，不展示文件总数、执行耗时或退出码。失败与冲突使用相同的红色状态，错误放在卡片底部；拒绝反馈也为红色。批准或拒绝后自动收起条目，历史差异和输出保留。

## 手动验证

- 在 Ask/Chat 中通过 `find`、`jq`、Python 或 `cat .env` 读取，确认不出现写入审批。
- 使用重定向、脚本或批量操作更改文件，确认审批前真实项目不变；拒绝后不变，批准后一次保存。
- 修改 manifest/design/outline/HTML/spec 后确认内容校验生效，页面状态和预览状态正常更新；范围外 HTML 仅允许对该次批准的源码版本补做渲染检查，不允许继续编辑。
- 创建目录、可执行文件和内部符号链接，确认保存和失败回滚保持文件属性。
- 尝试写项目外文件、通过硬链接写宿主文件、更改受保护资源及 Git 提交/推送，确认被阻止。
- 审批期间重启，确认保存的候选及输出不变、命令未重跑；审批期间修改项目，确认返回 `CONTENT_CONFLICT`；失败、超时和取消均不保存本地变更。
- 不传联网参数即可获取远端内容；下载到项目文件时按实际文件差异审批，拒绝后不保存下载文件。
