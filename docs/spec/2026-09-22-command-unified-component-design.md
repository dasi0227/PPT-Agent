# 命令统一容器设计

日期：2026-09-22。以用户确认的 [命令组件原型](../demo/2026-09-22-command-unified-component-demo.html) 为依据；完成态不显示成功勾选图标，长内容沿用正式界面原有的「展开全部／收起」设计。

## 统一结构

kickoff、handoff、commit、compact、rename、polish 继续共用 `CommandActivity`。运行、完成、失败、停止始终使用同一个白底、细灰边框、10px 圆角容器。

头部首行是中性小图标、命令名、时间与原有元信息，第二行是结果标题或状态文案。移除固定宽度的绿色命令标签。标题使用常规字重，可在窄栏换行；长分支名和其他元信息也可换行。

运行时停止按钮在右侧；失败或停止时同位置显示重试。完成时右侧只展示折叠箭头，头部文字和箭头都能展开结果，不展示额外成功图标。

## 进度与结果

三阶段进度位于容器内的分隔线下方。已完成阶段使用绿色勾选，当前阶段使用蓝色旋转指示，尚未开始使用灰色圆环。等待首个真实阶段时显示「正在准备」与旋转指示，不假定第一阶段已经开始。

进度继续由真实事件驱动，并保留现有的阶段最短展示时间和取消能力约束。减少动态效果设置下停止旋转，保留文字和阶段状态。

命令结果默认折叠，刷新、进入会话、历史恢复和执行完成均不自动展开；用户点击标题或箭头展开，重试时重置为折叠态。完成结果在同一个容器中展开，用细线与头部分隔，不另起独立卡片。正文直接复用 `LongContent`：默认限制 320px，沿用渐隐遮罩、居中的「展开全部」和「收起」按钮，仅溢出时出现控制按钮。

底部操作独立于正文截断区域。调整建议输入与重试、复制、新建会话或应用到输入框等操作优先排成一行，窄栏不足时自然换行。输入提示简化为「调整建议（可选）」，支持 Enter、独立重试按钮和中文输入法，不额外显示输入旁箭头按钮。主操作使用浅蓝背景。

## 实现范围与手动验收

本次调整共享命令组件、样式与默认折叠行为，保留各命令的调用、取消、结果、复制内容、重试与历史恢复。

按仓库约定，未运行自动化验证。手动关注六类命令的四种状态、等待阶段与实际阶段旋转、窄栏长标题和元信息、长正文展开及收起、建议输入和操作区，以及刷新后的恢复展示。
