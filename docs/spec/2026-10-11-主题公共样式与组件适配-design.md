# 主题公共样式与组件适配

日期：2026-10-11。状态：源码与预置资源已更新；未运行测试、构建或自动化视觉验证，待用户手动验收。

## 职责与入口

- `backend/internal/runtimeassets/base.css` 定义公共 class 的语义和默认实现。
- `backend/internal/designsystem/tokens.go` 定义主题必须提供的变量。
- `seed/assets/themes/*/theme.css` 为三套预置主题提供完整变量及局部角色样式。
- `seed/assets/components/*/index.html` 提供可加载、可改写的独立 HTML 参考。
- `html.md` 和现有提示词加载机制本轮不修改；新接口的 Agent 披露方式留待提示词设计阶段确定。

公共接口保持一致，主题决定外观，页面和组件决定内容结构与布局。固定画布仍为 1920×1080，删除主题中无实际画布控制能力的 `--stage-w`、`--stage-h`。不增加旧主题兼容分支。

## 公共 class

- `.slide-stage`：固定画布及默认内容颜色上下文。
- `.slide-content`：使用主题安全边距的默认内容区域。
- `.slide-title`、`.section-title`：页面标题与局部标题。
- `.slide-subtitle`、`.slide-body`：导语与正文。
- `.caption`、`.kicker`：辅助说明与标题前短标签。
- `.text-emphasis`：使用当前容器的强调色及强调字重。
- `.text-muted`：使用当前容器的次要文字色。
- `.text-highlight`：使用成对的高亮背景和文字颜色。
- `.card`：带内边距、边框、圆角和阴影的普通容器。
- `.card-soft`、`.card-outline`、`.card-accent`：与 `.card` 组合使用的柔和、透明描边和强调容器变体，每次选择一种。
- `.callout`：用于重要说明的独立内容块，默认没有阴影。
- `.status`：表达状态的文字标签。
- `.tone-success`、`.tone-warning`、`.tone-danger`、`.tone-info`：分别表达成功、警告、风险和信息，搭配 `.status`、`.callout`、`.metric-change` 或普通 `.card`，不与卡片表面变体混用。
- `.metric`、`.metric-value`、`.metric-label`：指标组、数值和标签。
- `.metric-unit`：指标旁的单位说明。
- `.metric-change`：变化量标签；正负号与好坏评价独立，状态色由显式 tone 决定。
- `.quote`：引用文字及其装饰线。
- `.slide-list`：直接用于 `ul` 或 `ol`，保留原生列表语义并统一标记与条目间距。
- `.image-frame`：图片容器，使用主题背景、边框和圆角，尺寸由页面布局指定。
- `.image-cover`、`.image-contain`：直接用于 `img`，在已确定尺寸的容器内分别裁切铺满、完整显示，二选一；不改变图片原始颜色。
- `.data-table`：基础数据表格。
- `.table-numeric`：用于表格数值单元格的末端对齐和等宽数字。
- `.table-focus`：用于表格行或单元格的成对背景、文字高亮。
- `.table-striped`、`.table-bordered`：与 `.data-table` 用在同一个 `table` 上，分别提供正文隔行底色和完整单元格边框，可组合使用；重点行、单元格优先于隔行底色。
- `.data-table > tfoot`：直接使用标准表尾结构呈现汇总行，无需新增类；默认文字色、背景和上边线随主题变化。
- `.pill`、`.divider`：普通标签与分隔线。
- `.chart-primary`、`.chart-secondary`、`.chart-accent`：原有的主、次、强调 SVG 填充角色。
- `.chart-series-1` 至 `.chart-series-8`：八个离散数据系列，系列与类别的对应关系应在整份演示中保持稳定。
- `.chart-highlight`、`.chart-muted`：图表的重点与弱化表达。
- `.chart-positive`、`.chart-negative`：数值相对零点的正负关系，不代表成功或风险。
- `.chart-line`：数据线，可与系列、强调或正负 class 组合使用。
- `.chart-axis`、`.chart-grid`：坐标轴和网格线。
- `.chart-label`、`.chart-value`：分类标签与数据值。
- `.chart-legend`：用于 `ul` 的图例布局，直接子元素 `li` 自动对齐标记与文字。
- `.chart-legend-key`：图例中的色块，与系列或图表颜色类用在同一个 `span` 上，例如 `.chart-legend-key.chart-series-2`；图例文字不跟随色块染色。
- `.diagram-node`、`.diagram-edge`、`.diagram-label`：关系图节点、连接线和节点内标签。

不同系列仍需标签、图例或其他可辨识标记；颜色不是唯一的信息编码。本轮未引入连续色阶、代码块或完整布局模板。

图片、表格变体、图例复用现有变量，没有增加主题必填项。图片说明和来源继续使用 `.caption`，图表标题使用 `.section-title`；加粗、斜体、上下标沿用标准 HTML 标签。完整流程、时间线、组织架构等保留为独立组件的设计方向。

## 主题变量

保留现有字体、六种字号、主次文字色、背景、卡片和图形基础变量，补充以下角色：

- `--color-on-surface*`：普通容器的正文、次要文字与辅助文字。
- `--color-on-surface-soft*`：柔和容器的正文、次要文字与辅助文字。
- `--color-on-accent-secondary`、`--color-on-accent-caption`：强调容器中的次要文字与辅助文字，与原有 `--color-on-accent` 配套。
- `--color-highlight`、`--color-on-highlight`：成对的高亮背景和文字。
- `--color-success*`、`--color-warning*`、`--color-danger*`、`--color-info*`：每种状态分别提供文字色、`-surface` 背景色和 `-border` 边框色。
- `--weight-emphasis`、`--leading-caption`：强调字重与辅助文字行高。
- `--space-1`、`--space-2`、`--space-3`、`--space-4`、`--space-6`、`--space-8`：4、8、12、16、24、32px 的少量通用间距档位。
- `--card-padding`、`--table-padding-x/y`、`--list-gap`、`--metric-gap`、`--quote-padding`：互相独立的内容内部间距。
- `--radius-sm/md/lg`：三个圆角档位，允许主题选择相同的值，例如全部为直角。
- `--shadow-sm`、`--shadow-card`、`--shadow-lg`：轻量、默认卡片和较强层次的阴影，允许主题选择 none。
- `--chart-series-1` 至 `--chart-series-8`：八个离散系列色。
- `--chart-highlight`、`--chart-muted`、`--chart-positive`、`--chart-negative`：图表强调、弱化与数值正负角色。
- `--chart-line-width`、`--chart-grid-width`：SVG 数据线和辅助线宽度。

`--color-primary` 继续表示普通表面上的强调前景色；`--color-accent` 与 `--color-on-accent` 组成强调背景和前景配对。两者用途独立，即使某个主题给出相同色值也不混用语义。

## 容器颜色继承

`--content-bg`、`--content-fg`、`--content-secondary`、`--content-caption`、`--content-emphasis`、`--content-border` 是公共容器建立的局部上下文，不属于主题必填变量，也不重定义全局主题变量。

`--chart-series` 是图表颜色类建立的局部系列颜色，供数据线、图例色块读取，也不是主题必填变量。原有主、次、强调颜色类与八个系列类使用相同的组合机制。

标题和正文继承容器文字色，辅助文字、指标、链接、SVG 标签等读取对应的局部角色。强调容器中的开放式指标、引用和列表因此能够获得匹配其背景的颜色。透明描边卡片沿用父容器颜色；有独立背景的子容器建立自己的配对。

```html
<aside class="callout tone-warning">
  <p class="section-title">交付风险</p>
  <p class="caption">关键材料仍待确认。</p>
</aside>

<div class="metric">
  <p class="metric-value">18<span class="metric-unit">天</span></p>
  <p class="metric-label">平均交付周期</p>
  <span class="metric-change tone-success">−3 天</span>
</div>

<path class="chart-series-2 chart-line" d="M20 80L80 40L140 60" />
```

## 组件默认适配主题

五个预置组件保留独立结构、布局及组件变量，通用视觉属性按“显式组件覆盖 → 当前容器角色或主题变量 → 独立预览备用值”解析。开放式组件使用父容器的文字角色；能力卡片拥有独立背景，因此建立自己的表面配对。

柱状图参考默认使用弱化色绘制普通数据，并用重点色突出选定项；多系列颜色由页面按数据含义显式选择。键值列表的进行中与已确认分别使用信息和成功语义。没有增加自动实例更新机制，已经复制进幻灯片的 HTML 仍由 Agent 显式修改。

## 生效与手动验收

共享 CSS 由后端嵌入；需要重新构建并启动后端。已经初始化到工作目录的主题和组件不会被启动流程自动覆盖；停止后端后，可使用现有维护入口 `python3 scripts/replace-theme-presets.py` 同步预置资源，再启动后端。该操作会覆盖同名预置资源的自定义正文，本轮未执行。自定义主题也需要直接补齐新契约。

1. 在三套主题间切换相同页面，查看普通、柔和、强调容器中的标题、辅助文字、列表与指标。
2. 查看四种状态的说明块、标签和变化量；确认负向变化也可显式表达有利结果。
3. 查看八系列图形、组合系列的数据线、坐标轴、重点和正负值配色，配合文字判断可辨识性。
4. 查看表格重点行、单元格、数值对齐，以及指标单位和变化量。
5. 加载五个组件，确认自动换主题及组件变量局部覆盖；再单独打开组件参考检查备用样式。
6. 检查换字体后的换行、内容容量、边界裁切及静态导出结果；样式关联本身不保证所有构图自动适配。
7. 检查图片裁切与完整显示、条纹表格和重点行组合、汇总行以及图例与图形颜色的一致性。

本地临时展示页 `tmp/2026-10-11-public-class-gallery.html` 展示公共类及其组合关系，并在后半部分展示全部主题必填变量和局部继承变量。它嵌入当前公共 CSS 与三套主题的副本，用于用户手动查看，不作为运行时样式来源。
