## 取消删除页面身份表

取消 `deleted_slides`：

- 页面引用按当前项目的大纲和页面记录校验，不再查询已删除页面的历史归属。
- 被删除页面的旧引用在输入框中标记为不可用，发送时提示移除或重新选择；后端拒绝不存在于当前项目的页面引用。
- 同步删除该表的写入、查询、恢复清理以及项目检查点数据库清单中的关联逻辑。
- 已删除页面的内容恢复继续由现有项目检查点机制承担。

## 取消增量数据库迁移

开发期直接切换数据库结构，不兼容旧数据：

- 取消按编号依次执行的 migration SQL，保留一份完整的最新建表 SQL，空数据库直接初始化到当前结构。
- 同步删除 `schema_migrations` 表及启动时逐文件执行、记录迁移的逻辑。
- 结构匹配的已有数据库正常使用；结构不匹配时明确提示用户重建，不自动删除数据，不提供旧数据转换、双读或兼容分支。
- 预置资源初始化继续作为独立、可重复执行的流程；普通启动不补回用户已删除的预置资源。
- 实施时同步更新初始化入口、相关文档及测试，最新建表 SQL 不再包含 `deleted_slides`。

## 最终表清单

| 表 | 当前用途 |
| --- | --- |
| projects | 项目身份、标题、主题选择和时间；工作路径由工作根目录与 ID 推导。 |
| slides | 当前页面身份及生成参考快照；正文由 PPT 文件承载。 |
| threads | 会话身份、命名控制和日志分配／投递水位。 |
| runs | 主任务模式、范围、所有权、取消／暂停控制及最新检查点。 |
| steering_inbox | 运行中输入去重和注入状态；正文引用会话输入事件。 |
| idempotency_records | 请求去重、小回执及工具准确重放所需结果。 |
| resources | 四类资源的名称、描述、启停等元信息。 |
| tags | 数据库标签字典、显示名称、顺序和系统标记。 |
| resource_tags | 资源和标签的关联，资源删除时级联清理。 |
| shortcut_settings | 用户快捷键覆盖配置与条件修改版本。 |
| command_executions | 六类命令的每次执行控制；输入和结果引用日志事件。 |
| thread_event_outbox | 事务已接受、等待可靠写入会话日志的事件意图。 |

最新定义见 [schema.sql](../../backend/internal/store/sqlite/schema.sql)。空库直接建表，已有库检查 application_id、user_version 和表清单；不匹配时拒绝打开，提示新建工作目录，保留旧数据。
