# 预览缓存与加载优化

## 主预览保活

- 主画布与源码、项目文档、设计稿、概览并列挂载，切换视图只隐藏主画布，返回时复用当前 iframe 与已有页面执行缓存。
- 隐藏画布设置 inert、移出可访问树，并通知运行时暂停动画和媒体；停用快捷键、选区创建与回放，返回预览后恢复。
- 左右侧栏显隐不重建 PanelGroup；各栏目使用稳定的 React key，保留中心画布实例。
- 切换项目仍隔离主预览，页面 HTML 实际改变时沿用运行时的内容更新机制。

## 验收边界

按项目约定仅进行源码与提交差异检查，未运行构建、自动测试或浏览器验证。人工检查预览与源码、设计稿、项目文档、概览之间往返，以及左右栏收起／展开、全屏放映、隐藏画布快捷键与选区隔离。

## 缩略图与概览

- 左侧缩略图与 HTML 概览统一使用懒加载图片组件，不再各自创建运行时 iframe；主画布继续实时执行页面。
- 新增 `GET /slides/:id/thumbnail?v=...`，复用共享渲染 Worker，将结果压缩为 640 × 360 WebP。单独限制缩略图生成并发为 1，渲染期间不占用项目创作锁。
- 缓存存于项目 `.runtime/previews/`，每页只保留一张图片与依赖索引；不写入 Agent 评审截图或修改评审事实。
- 内容快照 `hashes["thumbnail:<slide_id>"]` 绑定 HTML、可见主题／装饰和上次渲染实际请求的资源；图片缺失后补齐、图片替换、页码和主题等变化均会更新版本。
- 首次渲染发现资源后细化版本，允许同一输入的初始版本请求复用新缓存；HTTP 使用私有缓存与 ETag 校验，不将初始版本 URL 声明为永久不变。
- 发布前重新核对页面、外观和本地资源；过期结果不覆盖当前缓存。失败只影响对应缩略图，不回退到批量实时 iframe。

人工验收增加：首次／再次进入概览、滚动缩略图列表、修改 HTML／图片／主题／装饰，以及生成期间切换视图或删除页面。

## 刷新与资源复用

- HTML 预览接口在检查当前 `expected_hash` 后使用私有 HTTP 缓存与 ETag；未变化时返回 304，源文件变化仍返回原有冲突响应，错误不缓存。
- 字体 CSS 为内置字体文件添加内容哈希版本；服务端校验版本后允许长期缓存。无版本的共享运行时资源继续通过 ETag 重新验证。
- 带有效版本的 Logo 允许私有长期缓存；无版本请求重新验证，失效版本不返回旧图片。
- 主画布准备期间使用已有有效缩略图过渡，实时页面就绪后移除；`cached=1` 请求仅查现有截图，不触发生成。没有缓存时沿用已有加载状态。

人工验收增加：刷新后 HTML 的条件请求、字体复用、替换 Logo／主题后的正确显示，以及有／无截图缓存时主画布的恢复。

## 缓存边界与失效

- HTML 内存缓存按最近使用顺序保留最多 24 页，并限制字符串估算占用为 16 MiB；单页超过预算只保留当前展示所需状态，不写入公共缓存。局部加载状态最多 5 项，同页旧版本及时移除。
- 内容快照更新时清理已删除页面与过期 HTML，并取消对应请求；场景切换取消未完成请求，只复用内容哈希仍相同的纯 HTML。相同页面的重复加载共享一个 Promise，旧项目／旧版本响应不写回。
- 主画布只向运行时发送当前页附近最多 5 页的 HTML；目标页未就绪时暂停显示，保留原外层 iframe 与已有执行实例，就绪后再切换。
- 运行时继续最多保留 5 个 iframe；隐藏时取消相邻页预加载，显示时恢复，并清理不再保留页面的选区展示状态。
- 内容快照 `hashes["assets:<slide_id>"]` 跟踪缩略图已发现的本地资源。资源变化后重建对应页面执行实例，并为附件 URL 添加资源版本；单独切换主题仍更新外观，不因主题变化重建文档。
- 主题状态消息携带资源版本，主预览拒绝旧资源版本的就绪通知；选区会话也按资源版本隔离。
- 缩略图每页仅保留一份，删除页面后清理对应图片与索引，缓存清理不影响源文件或评审截图。

人工验收增加：超过 24 页的连续翻页、跳到未加载页再返回、快速切换项目、加载中切换项目历史、替换已引用图片，以及页面删除后恢复创作。
