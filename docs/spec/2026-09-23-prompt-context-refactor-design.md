## 1. 公开表达与内部定位分离

`core.output` 是公开表达的主要维护位置。模型调用工具时仍使用英文参数与稳定页面标识，公开表达采用当前页码和业务名称。

| 内部语义 | 公开名称 |
|---|---|
| manifest | 内容要求 |
| outline | 目录结构 |
| design | 全局设计 |
| slide spec | 页面设计稿 |
| slide HTML | 幻灯片 |
| key_message / elements / intent | 核心信息 / 内容元素 / 表达意图 |
| layout / role / direction | 布局建议 / 页面用途 / 视觉方向 |

`model.PublicText` 是共享公开文本入口；上下文层提供当前页码、已知内部标识和用户原文。覆盖最终回复、进度说明、计划及里程碑、问题及选项、范围申请说明、命令输出预览、润色、简报、命名、建议输入，以及压缩摘要的展示副本。主 Agent 和适用的命令提示词共享表达规范。

处理策略是转换已知产品引用，保留用户技术语境与代码：不再泛化删除所有大写下划线词；只有已注册错误码采用公开说明。围栏代码保留，已知项目私有标识仍屏蔽。用户明确提供的技术文件名可保留；任意英文单词不做全局机械翻译。字段自由文本的语言由提示词约束，结构化枚举由前端标签映射。

最终回复在进入模型历史、运行结果和公开事件之前生成同一份公开文本，避免下一轮继承未经处理的另一份最终回复。内部压缩摘要保留必要定位信息；显示的标题和摘要单独处理。真实命令文本保留用于确认实际执行内容；命令输出预览去除终端控制符并通过公开文本入口，敏感输出仍使用既有隐藏机制。

前端目标链接显示业务名称，悬浮标题不再使用本地路径；打开文件仍使用结构化地址。已删除页面不再回退到页面 ID。元素类型、布局标签、主题名称及未知枚举采用业务名称。历史活动中的结构化目标按当前目录重新计算页码；已经发送的普通自然语言回复保留其当时语境。

这是一组表达、投影和确定性处理措施，不是任意文本的语义保密证明。附件和渲染图的必要读取定位符、用户请求的代码、实际命令及程序使用的结构化地址仍按各自用途保留。真实模型是否遵守自然语言边界需要人工验收。

## 2. 模型数据投影

`contextengine.ModelSections / ModelValue / ModelResource` 负责模型输入边界，运行时对象不再整体作为常规上下文发送。

- 项目仅包含创作所需内容和标题，剥离项目、会话、运行、日志定位字段及无关时间戳。
- 目录拥有顺序、标题、页面用途与稳定标识，模型视图附当前页码。
- 每个 `page/<稳定标识>` 保存该页核心信息、必要设计稿和渲染状态；目录信息不再复制到每份页面摘要。选中页保留编辑所需的设计稿内容指纹。
- 初始页面上下文只包含 HTML 摘要；完整源码按需通过 `read_ppt` 获取。
- `read_ppt` 返回资源定位、原始资源的 `content_hash`、投影内容。HTML 返回完整源码。内容投影不会改变并发写入使用的资源指纹；读取目录同样返回当前页码。
- 常规工具结果使用显式模型观察，不再兜底序列化完整 `ToolResult`、公开链接或持久化证据对象。渲染保留可读取图片的必要定位符和诊断。
- 润色、简报和 Reviewer 也使用模型投影。运行期内部引用索引仍可用于检索实现，但不向模型发送无法通过公开工具读取的引用目录。

持久写入、目录调整、页面删除和渲染提交后刷新内存页面视图。普通页面操作只重读受影响页面；全局依赖改变时刷新相关页面状态。自动包含新页面的权限范围与运行命令同步更新。

## 3. PPT 创作判断

判断方法集中在 `core.agent`、`core.quality` 和已有三个 playbook 中：

- 只对会显著改变结果的缺失信息提问；复用已确认决定，自主处理可逆的措辞和布局。
- 根据受众、场景和目标组织叙事，每页承担明确任务，删去不支持核心信息的内容。
- 依据趋势、比较、构成、流程或关系选择图表；避免所有页面套用同一种卡片。
- 先精简、分组、调整阅读顺序或拆页，再考虑缩小字号。
- 区分事实、推断、示例与缺口，不为填满画面编造指标。
- 局部修改保留未受影响内容；整体创作可先做代表性页面，再延展视觉语言，这不是新增审批步骤。

## 4. 模式装配表

公共前缀顺序固定为 `core.agent → core.output → core.reference → core.quality → mode.<当前模式>`。

| 模式 | 后续模块 | 能力边界 |
|---|---|---|
| 讨论 / 追问 | `runtime.completion → runtime.next-input-suggestions` | 有 PPT 质量指导，不包含执行证据手册 |
| 规划 | `core.structure → core.html` | 只读，提交计划；不装配结束执行的合同 |
| 执行 | `playbook.deck → playbook.spec → playbook.slide → runtime.recovery → runtime.completion → runtime.execution → core.structure → runtime.next-input-suggestions → core.html` | 完成检查、依赖同步、渲染及必要视觉检查 |

执行模式固定装配三个简短 playbook：deck 负责叙事结构与共享资源，spec 负责语义内容，slide 负责页面实现；各自只维护一类判断规则。模型依当前任务采用适用部分，授权页数与普通阶段变化都不切换静态提示。规划始终获得资源归属和 HTML 约束，仍不可写入。

新增的 `runtime/execution.md` 承接执行完成条件和渲染验收。`runtime/completion.md` 只维护最终回复工具公共合同。参考资料可信边界与读取原则归 `core.reference`。Reviewer 复用 `core.quality`，继续只返回建议，不扩大权限或成为所有任务的必经流程。

## 5. 恢复信息按失败提供

常驻恢复提示仅保留原则。错误定义提供当前错误的说明和下一步；工具失败包含原因、受影响资源、修复动作及必要诊断。完成检查返回具体问题、`next_action` 和所需操作。现有失败次数、重复拒绝上限和权限校验保留。

缺少 HTML 证据时先调用渲染。渲染已执行实际静态校验，因此成功结果同时记录当前源码的静态证据与渲染证据，不再要求无意义地修改 HTML。真正的内容或依赖问题仍须修复。渲染失败保留检查结果和可用图片定位，便于判断问题。

## 6. 字段合同来源

领域 Schema 是字段类型、长度、枚举、必填项与示例的来源。`AuthoringSchema` 解析本地引用、排除运行时字段和只读主题字段，生成独立对象；作用域过滤不修改共享定义。

目录草稿复用领域字段，仅将正式身份改为操作内 `client_ref`。插入位置、字符串替换、并发指纹等仍归操作层。JSON Patch 的路径来自既有路径授权规则，值类型引用领域字段片段。工具定义中只保留被使用的 `$defs`，避免未使用定义占用输入。

`core.structure` 不再注入第二份完整 JSON 合同，只解释归属、依赖、只读主题与标识原则。运行时领域校验及权限检查仍是最终裁决者。

## 7. 按时间追加状态

提供者请求组织为：

```text
稳定系统提示 + 稳定工具定义
已有消息历史
本次用户输入
本次需要的状态基线 / 状态变化 / 所选资源
模型回复、工具观察
后续状态变化
```

`prepareAgentRequest` 是统一组装入口。模型请求、上下文估算及压缩判断使用同一份组装后的消息。首次只提供有意义的非空基线；后续保留已有消息前缀，分段比较规范化业务内容。

| 段落 | 内容与替代范围 |
|---|---|
| `run_command` | 当前模式、授权范围、创作选项 |
| `project_context / outline / design_context / theme_context` | 当前项目内容、目录、设计、主题合同 |
| `page/<标识>` | 单页内容与状态，互不触发重发 |
| `target_context / related_context / mentioned_pages` | 当前目标及引用定位 |
| `task/*` | 当前任务计划、要求、工作进度、变更、证据、有效技能与图片索引 |
| `available_resources` | 技能和组件的精简目录 |

同一段无变化则不追加；变化追加完整新值；删除发送 `null`，清空发送空值。新值完全替代该段旧值。任务段额外记录所属运行，使新任务明确替代上一任务执行状态。排序和 JSON 序列化稳定；比较忽略时间戳、运行编号等存储元数据。

运行时来源、段落键、哈希、资源可见性保存在消息内部元数据中，并写入模型历史；这些元数据不发送给提供者。识别运行时消息、当前用户指令与摘要时不依赖用户可伪造的文本标签。压缩只保留最新任务的必要输入和最近工具轮次；旧状态段不进入压缩正文，之后从当前真实状态重建基线。

`context_briefing` 不再重复计划、变更、证据和机械性的下一步，只提供当前视图之外的有效检索摘要；已修改页面的过期索引摘要不再注入。

OpenAI 原生续传同时校验此前完整输入前缀、工具配置及上一轮输出，不能仅按消息数量裁切输入。历史被改写、压缩、渲染图片释放或系统/工具变化时重新建立基线。恢复运行重新发送必要上下文，不恢复无法验证的提供者私有会话。日志记录系统与工具指纹及续传重建原因。其他适配器仍使用公共消息序列，不引入 OpenAI 专属的提示词要求。

## 8. 静态前缀与权限

模型可见包装只保留稳定模块名称及正文，不包含版本、源码路径和模块哈希。版本与指纹保留在内部日志或诊断元数据中。

工具名称按固定顺序排列。集合及 Schema 由模式与真实工具能力决定，不由页面 ID 列表、页数、目录是否存在或计划进度决定。执行模式固定声明全部创作操作；`outline.init` 始终声明，运行时拒绝对已有目录重新初始化。计划工具稳定声明当前模式可能使用的形态，实际操作仍受当前计划状态约束。

页面授权列表位于动态状态；设计稿与 HTML 写入、渲染逐次校验真实页面权限。内容要求、目录结构、全局设计默认可写，不再要求全局或对象权限；主题等只读字段仍遵守领域合同。共享资源可写不代表可以任意改动其余页面，产生范围外页面同步需求时仍须申请增加页面。全部页面范围自动包含本次新建页面，较窄范围则先插入取得真实标识，再申请增加这些页面。当前没有页面也不会生成动态枚举来更换 Schema。

以下情况会有意改变前缀或重建续传：切换模式、改变实际工具能力、修改提示词或领域合同、压缩历史、释放一次性渲染像素、恢复进程、切换提供者或模型。普通新增、重排、改名及页面授权范围变化不修改静态提示和工具定义。这里保证组装行为，不承诺未经真实请求验证的缓存命中率。

## 9. 正文按需与资源可见性

目录仅含稳定引用、名称、用途和标签。明确选择的技能、组件是本次需要的快照：首次追加正文一次。动态加载技能只返回本次新增或当前消息中缺失的正文，加载第二项不会重发第一项。

资源通过“类型 / 稳定引用 / 内容指纹”识别。正文变更发送新版本并标明替代关系。组件和 `read_ppt` 使用同样的可见性原则；重复读取仍返回当前资源指纹，但不重发仍在上下文内的正文。页面引用本身仅提供定位和用途。

压缩后根据保留消息及其元数据判断正文是否还存在，不能从摘要推测。缺失的有效技能恢复一次；组件和页面源码按需重读。已加载快照保存在运行状态与检查点，用户明确选择的技能和组件继续使用选择时快照。组件只在成功模型响应之后记为已交付，避免首次请求前压缩导致正文从未送达。普通附件沿用既有生命周期；渲染像素仅供下一次成功模型响应，之后释放，视觉结论保留为文本。

### 交互场景

| 场景 | 操作 | 期望 |
|---|---|---|
| 公开表达 | 要求解释或修改某页，检查回复、进度、问题、选项、计划、建议与工具链接 | 使用当前页码和业务名称；普通技术术语、用户代码保留；悬浮标题不出现内部文件路径 |
| 重排和删除 | 调整页面顺序并删除引用页，再继续讨论或修改 | 稳定标识不变，页码更新；删除状态明确；新请求没有幽灵页面摘要 |
| 最终历史 | 完成一轮，比较公开最终回复和模型历史中的最终文本 | 两者一致，不保留另一份未经公开处理的最终答复 |
| 讨论与追问 | 给出资料不足的创作需求；提供明确决定后继续 | 有内容判断；只问会影响结果的问题；不重复追问已定内容 |
| 规划 | 新建或修订计划 | 只读，不引导调用未开放的完成工具；批准后进入执行 |
| 完整创作 | 从空项目创作一份演示 | 目录、设计稿、HTML、实际渲染状态连贯；不编造缺失数据或导出结果 |
| 局部修改 | 只修改当前页表达或布局 | 不越权，不重写未受影响页面；所需检查与改动相符 |
| 页面范围与共享资源 | 选中一页，分别修改该页内容、布局和内容要求；再尝试编辑另一页 | 所选页设计稿与 HTML、全局资源可写，不申请对象权限；范围外页面仍需授权；共享修改的页面同步影响有明确处理 |
| 字段合同与并发 | 尝试过长字段、错误枚举、只读主题写入、过期内容指纹及范围外页面 | 错误可定位；合同和领域校验一致；越权仍被拒绝；冲突要求重读 |
| 渲染恢复 | 当前有效 HTML 缺少渲染证据，或渲染产生实际缺陷 | 先渲染，按真实诊断修复；不为了证据制造无意义改写 |
| 前缀 | 同一模式与能力连续调用，随后改单页、重排、清空计划 | 未变化前缀逐条保留；只追加变化；清空明确；静态提示和工具指纹不变 |
| 压缩与恢复 | 中途压缩或恢复任务，保留先前页面成果 | 重建最新必要状态；不会重复追加已存在的状态；不漏掉用户新输入 |
| 技能和组件 | 加载技能一、技能二，再重复加载；压缩后继续 | 第二次不附带第一项全文；可见正文不重复；有效技能恢复一次，组件按需读取 |
| 图片 | 读取渲染图后继续两轮，另附用户图片 | 渲染像素只进入下一次成功响应；用户附件不被一并释放 |
