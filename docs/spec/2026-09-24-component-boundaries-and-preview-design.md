## 最新职责决定

组件是可复用的表达单元，可以拥有 HTML、布局 CSS、独有视觉样式、SVG 及必要交互。主题负责页面默认外观与公共角色，不强制接管组件内部。本文替代 2026-09-23 主题方案中“预置组件只保留内容和组合布局、组件仓库固定使用主题”的部分。

- 页面通用标题、正文、容器仍可使用主题公共角色。
- 组件使用命名空间类名，所有内部样式限制在组件范围，避免污染页面。
- 组件可以保留自己的字体、颜色、材质和有语义的固定值，不自动添加 `.card`、`.pill` 等公共角色。
- 通过带默认值的组件专用变量提供调整入口，不自动映射主题变量。Agent 在内容需要时显式连接，例如：

```css
.page-summary .ppt-stat-badge {
  --stat-badge-accent: var(--color-primary);
  --stat-badge-secondary: var(--color-caption);
}
```

组件独立不意味着可以忽略页面可读性。Agent 需根据背景检查文字与图形，通过组件接口或局部容器解决对比问题，不覆盖全局主题变量。正式创作约束仍只维护在 `backend/prompts/core/html.md`。

## 组件仓库

`ComponentPreview` 提供 960×540 的白色中性工作台，等比缩放、隔离 iframe，只共享本地字体。它不加载主题 CSS、主题公共角色或 Runtime 装饰，也不请求任何主题接口。仓库呈现组件自身设计，组件放入 PPT 后由 Agent 决定是否显式适配。

五个预置组件均改为作用域 CSS 和各自变量：`--feature-card-*`、`--quote-block-*`、`--kv-list-*`、`--stat-badge-*`、`--svg-bar-*`。卡片保留自己的边界，指标与引用保持开放排版，图表拥有自己的系列和标签样式。

iframe 保留 `allow-scripts`，不开放 `allow-same-origin`。缩略图不可聚焦或交互，按可见区域首次加载。

## 预览稳定性与反馈

此前主题缩略图容器为 58×42，实际内容为 16:9，等比缩放后产生上下留白。主题和组件预览缩略图改为 16:9，轮廓不占用内部尺寸，保持完整画面而不裁切内容。

详情区使用 `RepositoryPreviewCache`：

- 首次访问才创建预览，此后保留已连接的 iframe；来回切换只改变可见性，避免重新执行页面和重复等待字体。
- 主题缓存以主题 ID、外观指纹和示例类型为键；组件缓存以 ID 和 HTML 内容为键。元数据编辑不使内容缓存失效。
- 最多保留最近访问的九份详情预览，可容纳三个内置主题的全部三个示例。未显示的内容禁止交互并从辅助技术中隐藏，同时保留尺寸供 Runtime 正确缩放。
- 资源删除、版本变化会移除对应旧预览。离开仓库页面或主动刷新会释放页面内缓存；刷新也清除示例 HTML 请求缓存。此设计不承诺跨刷新永久缓存，也不在启动时批量执行所有资源。
- 示例 HTML 请求在当前模块内合并，失败不缓存；缩略图首次可见后保留，普通选择和有结果的目录筛选不重建。

加载阶段统一使用 Lucide 灰色旋转图标，无白色通知横条，包含读屏状态并尊重系统减少动态效果设置。主题初次就绪前隐藏未完成的 iframe；同一页面切换主题时保留已成功的画面。失败保留文字和重试按钮；Runtime 初始化和组件加载有超时退出路径。

## 用户验收

新增/更新行为测试覆盖：首次访问与返回复用、缓存容量与版本失效、组件不依赖主题接口、主题加载和失败重试保留 iframe。未执行构建、测试、静态检查器或浏览器自动化。

```sh
cd frontend
pnpm tsc
pnpm test src/features/repository/RepositoryPreviewCache.test.tsx src/features/repository/RepositoryPages.test.tsx src/features/viewer/IsolatedSlidePreview.test.tsx
```

手工检查：

1. 组件仓库显示自身样式；网络面板无主题 API 请求，停用主题服务不影响组件列表和详情。
2. 主题缩略图上下无白边，内容完整可见。
3. 在三个主题、封面/内容/图表之间来回切换，已打开的组合不出现重复加载，iframe 节点保持不变；组件详情返回后同样复用。
4. 首次慢加载只出现灰色转圈，加载后消失；主题资源加载失败时显示重试，解除阻断后可恢复。
5. 刷新目录后读取新资源；删除组件或主题后旧预览被释放，元数据修改不重建内容。
6. 在项目页切换主题，已成功画面保留、选区与重试正常；组件通过自己的变量显式适配且不改变其他页面元素。

后端创作合同内嵌于服务，需使用新构建的后端；前端更新需重新加载。`DESIGN.md` 未修改。
