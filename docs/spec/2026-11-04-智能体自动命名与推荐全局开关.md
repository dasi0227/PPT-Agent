# 智能体自动命名与推荐全局开关

## 行为

- 设置页「智能体」新增「开启自动命名」「开启下一步推荐」，均默认开启。
- 两项为全局自动触发开关，与各会话已有的自动命名／自动建议设置共同生效；关闭全局开关不改写会话自己的偏好。
- 全局关闭时，会话面板对应开关显示关闭且不可修改。手动命名、点击生成名称和点击「立即生成」建议仍可使用。
- 自动任务在触发、模型请求及结果返回阶段读取最新设置，关闭后停止新的自动触发，并丢弃检查时已经失效的自动结果。已有名称和已生成的建议保留。

## 配置与协议

在既有 `agent` 配置、`GET /settings/agent` 和 `PUT /settings/agent` 中增加：

| 字段 | 类型 | 默认值 |
| --- | --- | --- |
| `auto_rename_enabled` | boolean | true |
| `auto_suggest_enabled` | boolean | true |

保存沿用配置文件原子替换和 revision 冲突校验；PUT 必须同时提交两项新字段及原有设置。前后端直接切换新接口结构，不增加旧协议兼容或历史数据迁移。保存后动态生效，后续启动从配置文件恢复。

## 界面

设置页复用现有设置行与 Switch，仅增加上述两个标签。发送／停止按钮复用现有交互颜色，常态使用透明背景和无描边，保留原有尺寸、禁用和危险操作反馈。

## 人工验收

本次不运行构建、自动测试或浏览器验证。重启后端后，分别检查开关保存、刷新和重启后的状态；关闭时不再自动命名／推荐；重新开启后按会话偏好触发；关闭时显式生成和手动命名仍可使用；输入栏发送／停止状态保持协调。
