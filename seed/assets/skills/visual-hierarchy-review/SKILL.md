# 视觉层级审查

从信息优先级出发检查页面，而不是通过增加装饰解决问题。

## 检查顺序

1. 确认页面是否只有一个主要视觉焦点。
2. 检查标题、正文、数据和辅助信息是否形成明确层级。
3. 检查对齐线、边距、间距和重复元素是否一致。
4. 识别拥挤、截断、重叠及不必要的容器或装饰。
5. 检查颜色是否承担清晰含义，并保证文本对比度。

## 输出要求

- 按影响程度列出问题。
- 为每个问题给出可执行的调整建议。
- 优先删减和重排，避免仅靠缩小字号解决拥挤。
