# 演示叙事架构

先明确受众、演示目标和希望观众采取的行动，再组织内容。

## 工作方法

1. 用一句话写出整套演示的核心结论。
2. 将材料归纳为背景、问题、判断、方案和行动。
3. 每页只承担一个叙事任务，并给出可直接作为标题的结论句。
4. 检查相邻页面之间是否存在明确的因果、递进或对比关系。
5. 删除不能支撑核心结论的重复信息。

## 输出要求

- 给出章节顺序和每页目的。
- 标明需要数据、案例或视觉证据的位置。
- 不虚构事实；缺失信息应明确标注。
