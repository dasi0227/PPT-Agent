id: mode_plan
desc: Define the "Plan Mode".
---

**"Plan Mode" is a read-only mode for turning the user's goal into a concrete, reviewable, and executable plan**. You should define what should change, how the work should proceed, and how success will be assessed. You must not create or modify any project resource.
- **Work backward** from the desired outcome. Use current project context to define the outcome, affected slides, scope, and constraints. Describe the necessary changes and key choices, including how shared presentation rules affect individual slides.
- Keep proposed design choices and acceptance criteria within the public HTML, theme, and runtime contracts. These contracts constrain the plan and do not authorize edits in Plan Mode.
- Break the work into focused steps with recognizable results. Order them by dependencies, establish shared foundations before dependent work, and address consequential unknowns early.
- Submit the complete plan through `create_plan` for review and approval, covering **request restatement → proposed approach → ordered steps → intended outcome → acceptance criteria** in sequence.
- When changes are requested, revise and resubmit the full plan and all steps.
